# 06 · 题库与命题规范

## 1. 题库定位

题库服务于三件事：**检验知识点是否真的掌握**、**暴露薄弱点**、**提供可重复的练习流**。因此题库不是越多越好，而是「每个高频考点都有可诊断的题」。v1.1 目标 150–180 题，七科均衡（每科 ≥ 20 题），平均每题绑定 1 个主考点。

## 2. 题型定义

| 类型 | 编码 | 选项 | 判分 | 适用 |
| --- | --- | --- | --- | --- |
| 单选 | `single` | 4 项 | 选对得分，选错 0 | 概念辨析、计算结论、机制判断 |
| 多选 | `multiple` | 4 项（≥2 正确，≤3 正确） | 默认「全对满分、漏选半分、错选 0」 | 特征列举、多条件判断 |
| 判断 | `judge` | 正确 / 错误 | 二值 | 命题真伪、常见误区 |
| 简答（预留） | `short` | 无 | 关键词命中自评 | v1.1 起支持 |

### 2.1 多选判分策略

```js
// partialCredit = true（默认）
if (错选任一) score = 0
else if (全对) score = 1
else if (漏选且未错选) score = 0.5
// partialCredit = false
score = (答案集合完全相等) ? 1 : 0
```

会话得分 = Σ 单题得分 / 题数 × 100，四舍五入到整数。正确率（用于统计与诊断）按**全对**口径统计，与得分分开，避免「漏选半分」抬高掌握度。

## 3. 命题原则

1. **单一考点**：一道题只考一个知识点，题干不叠加两个不相关结论。跨考点综合题放在「综合」难度，并只绑定主考点，其余在 `tags` 标注。
2. **干扰项有来源**：错误选项必须对应急混概念、常见误算或反例，不得为凑数编造无意义选项。
3. **题干自足**：不依赖上一题条件；不出现「下列说法正确的是」后面跟四个都对的表述。
4. **避免绝对化陷阱**：除非考点本身就是「一定/不一定」的辨析，否则不在选项中滥用「总是」「绝不」。
5. **计算题给足条件**：地址位数、页大小、时钟频率等必须显式给出，单位统一，答案唯一。
6. **题目可以取自教材与真题**：直接引用、改写、整卷收录都可以；`source`、`year` 只用于检索与归类，不再强制填写，也不要求在 UI 标注「改编」。
7. **解析必须解释错误项**：至少说明一个典型错误选项为什么错。

## 4. 难度标定

| 等级 | 编码 | 判据 | 建议占比 |
| --- | --- | --- | --- |
| 基础 | 1 | 单步回忆或直接套公式；无需综合分析 | 40% |
| 进阶 | 2 | 需两步推理或区分相近概念 | 45% |
| 综合 | 3 | 多条件联立、跨节知识协同、计算链 ≥ 3 步 | 15% |

难度由命题者先标，运行后再用答题数据校准：若某题长期正确率 > 90% 且难度标 3，标记「难度高估」；< 30% 且标 1 标记「难度低估」。校准结果写入维护清单，不自动改数据。

## 5. 题目标识与年份

- `source` 为可选项：`original`（自编）、`adapted`（按某年卷改写）、`real`（原卷）。填与不填都不影响作答与组卷。
- `year` 只表示考点或卷面对应的年份，不要求展示。
- UI 默认不在题干上打「改编」角标；需要追溯时在详情页看字段即可。

## 6. 解析结构

```
结论：正确答案 + 一句话理由
推导：2–5 步关键推理（计算题给中间值）
陷阱：至少一个错误选项的错因
延伸：可选，关联知识点 id 或记忆口诀
```

示例（页式存储）：

> **结论**：选 B。页表项指向物理页框号，虚拟页号经页表映射后与页内偏移拼接得到物理地址。
> **推导**：VA = 虚页号(20 位) + 偏移(12 位) → 页表基址 + 虚页号×4 取表项 → 物理页框号(20 位) + 偏移。
> **陷阱**：A 把页表项当成页框内容；C 忽略了偏移不参与映射。
> **延伸**：见 `k-os-018`，多级页表在 64 位下的切分。

## 7. 编码规范（纯文本标记）

题干与选项支持以下行内标记，渲染层负责转 DOM（不解析 HTML）：

| 写法 | 渲染 |
| --- | --- |
| `**文本**` | 加粗 |
| `` `code` `` | 等宽内嵌块 |
| `^{上标}` | 上标（`2^{10}`） |
| `_{下标}` | 下标 |
| `[[k-os-018]]` | 内链知识点 |
| `~~文本~~` | 删除线（用于错误命题） |

代码块用三反引号包裹，渲染为可横滚的等宽块。所有标记在构建期校验配对，未闭合直接报错。

## 8. 组卷规则

| 参数 | 规则 |
| --- | --- |
| 科目 | 多选，至少 1 科 |
| 题量 | 10 / 20 / 30 / 自定义 5–60 |
| 难度配比 | 默认 4:4:2（基础:进阶:综合），可按科目微调 |
| 知识点覆盖 | 抽样时以知识点为分组单位，先保证覆盖广度，再补同点题 |
| 去重 | 会话内题目 id 唯一；同一知识点的题最多占 30%（题量 ≥ 10 时） |
| 最近做过 | 组卷优先排除近 3 天内做过的题；可用题不足时按「最久未做」补 |
| 真题模式 | 按年份 / 考点筛选，优先同科目同难度 |

### 8.1 组卷算法（`core/paper.js`）

```
输入: subjects[], count, mode, filters
1. 候选池 = 题目 ∩ 科目 ∩ 过滤条件 ∩ 未下架 ∩ 非近期(3d)
2. 若 |候选| < count → 放宽「非近期」→ 再放宽「难度配比」→ 仍不足则截断并提示
3. 按知识点分桶; 打乱桶顺序; 轮转取桶 (每桶每次取 1 题)
4. 每轮检查单知识点占比 ≤ 30%, 超出则跳过该桶
5. 难度配额: 每 10 题按 4/4/2 分配, 余数补给进阶
6. 输出题目 id 数组, 顺序再做一次整体打乱(保证题号不暴露难度)
```

冷启动（候选不足 5）时给出提示：「本题库该组合仅 N 题，已为你全部抽入」。

## 9. 题库质量校验

| 检查项 | 类型 | 规则 |
| --- | --- | --- |
| 答案合法性 | 硬错误 | answer key 必须存在于 options |
| 多选题项数 | 硬错误 | 正确项 ≥ 2 且 ≤ 3 |
| 判断题答案 | 硬错误 | `T` / `F` |
| 主考点存在 | 硬错误 | knowledgeId 可解析 |
| 解析长度 | 硬错误 | 30–260 字 |
| 题干预重复 | 告警 | 归一化后相似度 > 0.9 |
| 选项重复 | 告警 | 同题选项文本重复 |
| 选项长度失衡 | 告警 | 最长/最短 > 4 倍（易被猜） |
| 知识点覆盖 | 告警 | 某知识点 0 题或 > 10 题 |
| 难度分布 | 告警 | 偏离 4:4:2 超过 15% |

## 10. 错误类型与复盘（预留）

v1.0 只记录「答错 + 所选选项」，v1.1 引入错因标注（概念混淆 / 计算失误 / 审题错误 / 记忆缺失），用于：

- 错题聚类：同一知识点的错误若集中在「计算失误」，推荐计算专项而非概念重读。
- 诊断加权：概念混淆权重高于审题失误。

数据结构预留 `mistakes[qid].reason`，v1.0 不写入。

## 11. 题库扩充流程

1. 从薄弱点排行取「题量不足」的知识点（< 3 题）。
2. 按本章高频考点补 2–3 题，难度覆盖 1/2/3。
3. 走 `scripts/validate-data.mjs`，通过后本地抽查 10 题（答案与解析）。
4. 合并发布，`dataVersion` +1。
5. 观察 7 天答题数据，校准难度标记。

## 12. 题目数量基线

| 科目 | 知识点 | 题目 | 每点均题 | 备注 |
| --- | --- | --- | --- | --- |
| 数据结构 | 28–34 | 32–40 | ~1.2（首版偏低，靠真题模式补足） | 算法与复杂度题占 40% |
| 计算机组成 | 28–34 | 32–40 | 同上 | 计算题需给全参数 |
| 操作系统 | 28–34 | 32–40 | 同上 | 进程/内存/文件三块均衡 |
| 计算机网络 | 24–30 | 28–36 | 同上 | 分层协议与 TCP 为重点 |

v1.0 实际交付以数据文件为准，构建校验强制每科 ≥ 20 题、每科 ≥ 20 知识点。
