# 17 · 公共课扩展与多学科设计

> 版本：v1.1
> 状态：已实现
> 关联：03 领域模型、05 内容体系、06 命题规范、08 诊断算法、11 测试验收

## 1. 背景与目标

v1.0 只覆盖 408 四门专业课，用户在实际备考中同时需要复习数学、英语、政治。若公共课散落在其它工具里，「薄弱点诊断」与「每日任务」会被割裂，积分与卡册也无法反映全科投入。

v1.1 的目标是把平台从「408 单科工作台」扩展为「全科考研工作台」，同时保持三项不变：

1. **数据仍然是纯静态、构建期打包**，不引入后端。
2. **存档结构不推翻**，旧存档可直接继续使用。
3. **内容生产标准不降低**，新增科目同样遵守「知识点 ≥ 3 要点 + 书页映射 + 原创题 + 解析」。

## 2. 学科模型

### 2.2 设计取舍

- **数学拆成三本书而不是一本合订本**：高数、线代、概率的章节体系差异大，拆开后「章节 → 知识点 → 书页」的映射更准确，也允许用户只挂载其中一本。
- **英语与政治可直接使用原卷与大纲原文**：按个人复习使用入库，书目 author 照实登记，不要求自编改写。
- **科目 id 不复用 408 前缀**：`math`/`en`/`pol` 短且语义明确，颜色令牌为 `--sub-math`、`--sub-en`、`--sub-pol`。
- **知识点编号前缀**：`MATH-`、`EN-`、`POL-`，与 408 的 `DS-/CO-/OS-/CN-` 并列，便于检索时按编号定位。

### 3.2 数学内容映射

| 模块 | 章节 | 知识点示例 |
| --- | --- | --- |
| 高数 | 极限、微分、积分、多元、重积分、级数、微分方程 | 极限存在性、中值定理、二重积分、幂级数 |
| 线代 | 行列式、矩阵、方程组、特征值 | 秩与基础解系、相似对角化 |
| 概率 | 事件、随机变量、数字特征、大数定律 | 期望方差、正态分布 |

### 3.3 英语内容映射

词汇与构词 → 长难句与语法 → 完形 → 阅读 → 新题型 → 翻译 → 写作，七章对应考试题型顺序。题目以「辨析 + 策略」为主，不复制真题原文。

### 3.4 政治内容映射

马原 → 毛中特 → 史纲 → 思修法治 → 时政，五章对应大纲五部分。表述保持教材口径，不引入评价性内容；时政题只考方法论与答题结构。

## 4. 数据结构变更

### 4.1 静态数据

新增文件：

```
src/data/knowledge/math.js | en.js | pol.js
src/data/questions/math.js | en.js | pol.js
src/data/public-cards.js
```

聚合入口 `knowledge/index.js`、`questions/index.js` 追加三组数据；`cards.js` 改为 `[...coreCards, ...cardsPublic]`，导出接口 `cardsBySubject`、`cardById`、`rarityOrder`、`rarityMeta` 保持不变。

### 4.2 书目

新增 5 本书：

| bookId | 科目 | 章节数 |
| --- | --- | --- |
| `book-math-calculus` | math | 7 |
| `book-math-linear` | math | 4 |
| `book-math-prob` | math | 5 |
| `book-en-core` | en | 7 |
| `book-pol-outline` | pol | 5 |

章节 id 采用 `m-ch*`、`ml-ch*`、`mp-ch*`、`en-ch*`、`po-ch*`，避免与 408 的 `ds-ch*` 冲突。

### 4.3 存档

`archive.settings.subjects` 初始值扩展为 7 科；旧存档中该字段只有 4 科时，缺省不自动追加，用户可在设置中勾选。`schemaVersion` 不变（仍为 2），因为新增科目只是数据枚举扩展，不改变字段结构。

导入校验中的 `app: "zhizhan-408"` 标识保留，用于兼容旧备份；产品更名不影响存档格式。

## 5. 界面适配

| 位置 | 适配方式 |
| --- | --- |
| 科目筛选 | 所有 `v-for="s in subjects"` 的筛选条自动变为 7 项；移动端允许横向滚动 |
| 雷达图 | 由固定四轴改为按数据长度动态生成 N 轴，角度均分，标签置于半径外 21px |
| 集章册 | 由 4 枚改为 7 枚，容器允许换行 |
| 书库 | 9 本书按科目分组展示，数学三本共享「数学」色 |
| 统计 | 科目面板 7 行；「全科入门」成就要求 7 科各完成 ≥ 1 次会话 |
| 默认主题 | 改为浅色（`data-theme="light"`），首次进入不再闪深色 |

## 6. 算法影响

- **组卷**：`buildPaper` 以知识点为桶，科目只作为过滤条件，新增科目无需改算法。
- **诊断**：`subjectStats`、`radar` 遍历全部知识点，自动覆盖 7 科。
- **冷启动**：`coldStartPath` 按科目取首个基础知识点，7 科各一条，首页展示前 4 条，其余可在统计页查看。
- **积分与抽卡**：卡池从 48 张扩到 84 张，概率与保底不变；重复卡碎片规则不变。
- **每日上限**：仍为 300，避免公共课加入后积分通胀。

## 7. 校验与测试

### 7.1 构建期校验

`scripts/validate-data.mjs` 对每个科目检查：

- 知识点 ≥ 20、题目 ≥ 20、知识卡 ≥ 12；
- 知识点章节与书页引用存在；
- 题目答案在选项内、多选正确项数量合法、解析 ≥ 20 字；
- 题干去空白后不重复。

当前输出：

```
知识点 153 · 题目 164 · 书目 9 · 知识卡 84
DS 25/26，CO 22/26，OS 24/26，CN 22/26，数学 20/20，英语 20/20，政治 20/20
```

## 8. 边界情况

| 情况 | 处理 |
| --- | --- |
| 7 科全选但题量 30 | 按知识点桶轮转，单点不超过 30%，保证覆盖 |
| 数学三本书只挂载一本 | 其它书的「打开书页」提示未挂载，不影响知识点浏览 |
| 英语长难句含代码/公式 | `RichText` 不支持公式，讲义统一用文字描述 |
| 政治表述更新 | 时政类知识点标注「以当年大纲为准」，题目避免具体会议届次 |
| 科目色在浅色下对比不足 | 浅色令牌单独定义更深的 7 种色值 |
| 移动端 7 个筛选芯片 | 横向滚动，不换行挤压 |

## 9. 可扩展性

新增科目只需四步：

1. 在 `subjects.js` 增加科目与颜色令牌；
2. 在 `books.js` 增加书目与章节；
3. 增加 `knowledge/<id>.js` 与 `questions/<id>.js`，在 index 聚合；
4. 增加 12 张卡到卡池。

校验脚本、路由、筛选、雷达、集章均无需改动。若未来加入 199 管理类联考或法硕，可沿用同一模型。

## 10. 风险与合规

- 数学书目只引用公开版本信息，不复制例题与习题。
- 英语、政治可直接使用真题原文与大纲原文，题目与解析可原样收录。
- 公共课讲义中的口径以公开教材与考纲常识为限，不涉及评价性内容。
- 所有内容仅供个人复习，不构成考试承诺。
