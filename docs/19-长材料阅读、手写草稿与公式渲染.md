# 19 · 长材料阅读、手写草稿与公式渲染

> 版本：v1.0
> 状态：已实现
> 关联：04 视觉规范、06 命题规范、18 真题原卷、20 英语原卷与共享材料
> 适用：英语阅读、政治材料分析、数学解答题，以及未来任何「材料 + 多问」题型

## 1. 问题定义

传统「题干在上、作答在下」的单栏题卡，在三类场景里会失效：

1. **长材料**：英语阅读一篇 400–600 词、政治材料 300–600 字，材料与设问一起堆在题目栏，用户必须反复上下滚动，设问一旦滚出视口就失去上下文。
2. **边读边画**：做阅读定位、政治材料圈关键词、数学草图时，用户需要一支「纸上的笔」。如果草稿要求切到独立画板，就破坏了阅读的连续性；如果草稿留在页面上，又会污染题干、干扰后续题目。
3. **公式排版**：数学题干、选项、参考答案含大量分式、积分、矩阵，纯文本会把 `\int_0^1` 直接暴露给用户，既不可读也不专业。

本章给出三者的统一方案：**材料独立成栏、草稿成为可随时擦除的透明层、公式在文本层内联渲染**。

## 2. 长材料分栏

### 2.1 布局

作答页由两栏扩展为三栏：

```
┌───────────────┬──────────────────────────┬────────────┐
│  材料栏        │  题目 + 作答              │  答题卡     │
│  sticky        │  随页面滚动               │  题号网格    │
│  独立滚动       │                          │            │
└───────────────┴──────────────────────────┴────────────┘
```

| 视口 | 布局 |
| --- | --- |
| ≥ 1200px | 三栏：材料 `minmax(300px, .84fr)`、题目 `minmax(440px, 1.16fr)`、答题卡 220px；整页最大宽 1440px |
| 900–1200px | 两栏：材料占整行、题目与答题卡并排；材料高度限制为 38vh，可展开 |
| < 900px | 单列：材料 → 题目 → 答题卡；答题卡移入底部抽屉，材料默认 38vh |
| 打印 | 材料在前、题目在后，不保留 sticky 与独立滚动 |

材料栏在桌面端 `position: sticky; top: 84px`，最大高度 `calc(100vh - 108px)`。题目再长，材料标题与设问都留在视口内。

### 2.2 材料分块

政治材料分析题常含「材料 1 / 材料 2 / 材料 3」，合并成一段会让用户找不到设问对应的材料。数据结构采用块数组：

```js
material: {
  title: '材料',
  blocks: [
    { label: '材料 1', text: '……' },
    { label: '材料 2', text: '……' },
    { label: '材料 3', text: '……' }
  ],
  source: '2024 政治原卷'
}
```

- 只有一块时不显示 tab，直接铺满。
- 多块时以 chip tab 切换；每个块独立记忆滚动位置，切回时恢复到上次读到的地方，而不是回到顶部。
- 切题时块索引与滚动位置一起重置，避免把上一题的材料位置带到下一题。
- 材料原文由 `withMaterial()` 从题干中切出，**只切分、不改写**；设问只保留「（1）……（2）……」部分。
- 拆分规则：以「结合材料回答问题」「阅读材料回答问题」等提示句为界，取其后、第一个 `（1）` 之前的原文；找不到 `（1）` 时整段保留。规则失败则退化为整段材料，不丢内容。

### 2.3 阅读工具

| 工具 | 行为 | 理由 |
| --- | --- | --- |
| 字号 A− / A＋ | 13–19px，逐级 1px | 长文阅读对字号敏感；不引入滑块，减少误触 |
| 收起材料 | 收进顶部「看材料」条 | 做纯计算或回看时让出宽度 |
| 独立滚动 | 材料栏内部滚动，`overscroll-behavior: contain` | 滚到材料底部不会把整页带着滚 |
| 来源脚注 | 底部固定一行 | 明示原文来源、未改写 |
| 材料题标记 | 题卡右上角 chip「材料题」 | 结果页与答题卡可快速识别 |

### 2.4 结果页回顾

交卷后题目栏不再需要作答，材料以可折叠的「回顾材料原文」形式放在解析上方。默认折叠，避免结果页被长文淹没；展开后按块展示，保留原文。

## 3. 手写草稿层

### 3.1 定位

草稿是「覆盖在题目栏上的透明纸」，不是独立页面，也不是笔记功能：

- 覆盖范围：题目栏 `.s-question`，含题干、选项、作答区，不覆盖材料栏与答题卡。
- 坐标：笔迹锚定在**题目内容的文档坐标**，页面滚动时随内容一起移动，而不是固定在视口。
- 生命周期：只在当前题有效；切题、切页、刷新、关闭即销毁；不写 `localStorage`、不进存档、不上传。
- 入口：右下角浮动按钮「草稿」。进入后显示底部工具条，退出后画布隐藏但当前题笔迹保留，重新打开可继续。

### 3.2 绘制

- 使用 Pointer Events，统一鼠标、触控、手写笔；`setPointerCapture` 保证笔画出画布边界仍连续。
- `touch-action: none` 防止手写时页面被滚动或缩放。
- 可选「仅手写笔」：过滤 `pointerType === 'mouse'`，方便有触控板的笔记本用户。
- 画布按 `devicePixelRatio` 缩放，CSS 尺寸与内容区一致；DPR 上限 2，避免 4K 屏显存过高。
- 笔宽 3 档（细 / 中 / 粗），按 DPR 同步缩放；颜色 5 种，从 CSS 变量取值，深浅主题自动适配。
- 贝塞尔平滑：每三个采样点用二次曲线连接，低采样率下也不出现折线感。
- 撤销按「一笔」为单位；清空需二次确认；橡皮以 `destination-out` 擦除，不产生白色痕迹。

### 3.3 跟随滚动与尺寸变化

- 画布 `position: absolute; inset: 0`，父容器为题目栏；页面滚动只改变画布的视口位置，不改画布坐标，笔迹自然跟随。
- `ResizeObserver` 监听题目栏高度：字号、材料收起、窗口缩放导致内容变高时，重设画布尺寸并按矢量数据重绘，笔迹不丢失。
- 画布高度设有上限（当前实现按内容高度，浏览器上限内）；超长题目不建无限画布。

### 3.4 清除规则

| 事件 | 笔迹 |
| --- | --- |
| 切到下一题 / 上一题 / 答题卡跳题 | 清空并退出草稿 |
| 切到结果页、首页、其他路由 | 清空（组件卸载） |
| 刷新 / 关闭标签页 | 清空（无持久化） |
| 交卷 | 清空 |
| 同一题内收起再打开 | 保留 |
| 切换深浅主题 | 保留，颜色随主题重绘 |
| 浏览器窗口缩放 | 保留，按矢量重绘 |

「不保存」是硬约束：不写存档、不进入导出 JSON、不做「草稿历史」。用户如果需要长期保留，应使用纸笔或系统截图。

### 3.5 与文本作答的冲突

- 草稿激活时，画布接收指针，题干文本不可选中；这是有意的，避免手写时误选文字。
- 需要复制题干时，先收起草稿。
- 主观题文本域在画布下方，草稿激活时仍可通过工具条的「收起」恢复交互；不做「画布穿透到输入框」的复杂命中测试。
- 键盘快捷键（数字选项、方向键切题）在草稿激活时仍然生效，但输入框聚焦时不触发。

## 4. 公式渲染

### 4.1 方案

选用 **KaTeX 0.16**，构建期打包，运行时同步渲染：

- `RichText` 先按 ``` 代码块切分，代码块内不解析公式；
- 再按 `$$...$$`（块级）与 `$...$`（行内）切分；
- `katex.renderToString()` 输出 HTML，`throwOnError: false` 保证单条公式坏了不拖垮整段；
- 渲染失败回退为 `<code>`，保留原始 LaTeX 可读；
- 块级公式 `display: block`、横向可滚，长矩阵不会撑破题目栏；
- 保留原有 `**粗体**`、反引号、`^{}` / `_{}`、`[[知识点]]`、`~~删除~~` 语法，公式优先级高于行内标记。

### 4.2 数据约定

- 题干、选项、参考答案、评分要点中的公式统一用 `$...$`；多行推导、矩阵、分段函数用 `$$...$$`。
- 反斜杠在 JS 字符串中需转义；录入时优先使用 `String.raw` 模板，减少 `\\int` 噪音。
- 中文与公式之间不加空格，KaTeX 会自动处理间距；单位用 `\mathrm{}`，避免斜体。
- 公式内的 `%`、`&`、`#` 需转义；`\text{}` 内可写中文。
- 不把整段题干包进一个 `$$`，否则行内文字会变成公式正体。

### 4.3 性能

- KaTeX 与 CSS 被打进独立的 `RichText` chunk（约 268 kB / gzip 79 kB），首屏不加载，进入题目/解析页才拉取。
- 渲染结果按题目文本缓存（`computed`），滚动、重绘不重复调用 `renderToString`。
- 单题公式数量超过 200 条时，建议改为虚拟滚动或分块渲染；当前原卷规模远低于阈值。

### 4.4 可访问性

- KaTeX 输出自带 MathML（`output: 'html'` 下仍保留 `<span class="katex-mathml">`），屏幕阅读器可读。
- 块级公式容器加 `role="math"` 与 `aria-label`（原始 LaTeX），便于复制与读屏。
- 公式横向滚动区保留键盘焦点，触控板可横向滚动。

## 5. 填空题与自评

数学一、二的原卷含 6 道填空题（每题 5 分）。填空题没有选项，但也不需要按「主观题」的步骤要点评分：

- 数据层：`type: 'subjective'`、`subtype: 'fill'`、`score: 5`，`answerText` 存标准结果，`referenceAnswer` 存「答案 + 简要过程」。
- 题卡标记显示「填空」，不显示「主观题」。
- 作答区为单行/多行文本，允许输入 LaTeX 或普通字符；不自动判分，交卷时进入自评，默认 0%，用户按结果对错选择 0 / 20 / … / 100%。
- 评分要点只有一条「结果正确」，合计等于满分；构建校验允许 `answerText` 的参考答案短于 4 字时跳过长度检查。
- 结果页展示「我的答案 / 标准答案」，数学符号按 KaTeX 渲染。

主观题（解答题、材料分析）仍按 18 章的六档比例自评；填空题与主观题共用自评弹窗，但文案区分「参考答案」与「标准结果」。

## 6. 其它必要设计

### 6.1 阅读与作答的焦点管理

- 进入题目时焦点落在题卡标题，不自动聚焦输入框，避免移动端一进来就弹键盘。
- `Tab` 顺序：材料栏工具 → 选项 → 作答区 → 上一题/下一题 → 答题卡。
- 材料栏与题目栏各自滚动，互不抢焦点；滚轮在材料栏内滚动材料，在题目栏内滚动页面。
- 桌面端支持 `Alt + M` 展开/收起材料；`Alt + K` 打开/收起草稿列入后续，当前通过浮动按钮操作。

### 6.2 错题与自评的边界

- 客观题未作答计 0 并进错题；主观题不进错题本（无法重练），但按自评比例计入掌握度。
- 填空题按「主观题」处理：不进错题重练，结果页标注自评比例；如后续要做「填空重练」，需新增「答案归一化比较」能力，不能直接复用客观题判分。
- 自评比例 ≥ 60% 记为答对；< 60% 记为答错，但不入错题本。

### 6.3 计时与长材料

- 材料栏独立滚动不暂停计时；切题、切页不暂停。
- 材料展开/收起不重置计时。
- 计时到 0 自动交卷，主观题与填空题按 0 分，不弹自评，避免用户被阻塞。
- 中途退出保留答案草稿 24 小时；材料阅读位置不持久化（属于瞬时状态）。

### 6.4 移动端与手写笔

- 移动端材料默认 38vh，可上拉至 70vh；题目栏仍可滚动。
- 手写笔优先：`pointerType === 'pen'` 时不触发页面滚动；手指默认也可画，但可在工具条切换「仅手写笔」。
- 小屏工具条压缩为两行：颜色/笔宽一行，撤销/清空/收起一行；按钮最小点击区 36×36。
- iOS Safari 的 Pointer Events 与 `touch-action` 已覆盖；不支持 Pointer Events 的旧设备降级为不可用，不阻塞答题。

### 6.5 数据与隐私

- 草稿不落盘、不上传、不进导出；关闭即消失。
- 材料原文随题目静态打包，不请求第三方接口。
- KaTeX 全部本地渲染，不调用 CDN，避免公式内容外泄与网络依赖。
- 公式源码会进入构建产物，属公开试卷内容；不包含用户输入。

### 6.6 视觉

- 材料栏与题目栏同底色，仅以 1px 边线与 14px 圆角分隔；不使用重阴影，保持「纸面」感。
- 草稿工具条使用磨砂半透明底，避免遮挡题干；激活时画布不改变题干颜色。
- 笔色取主题变量：墨（主文本）、朱（错误/强调）、青（链接/正确）、紫（标记）、金（高亮）；深色主题下自动提亮。
- 公式字号跟随正文 1.02em，不单独放大，避免行距跳动。

## 7. 边界情况

| 情况 | 处理 |
| --- | --- |
| 材料为空或拆分失败 | 退化为整段材料；仍显示材料栏，不显示空 tab |
| 材料块只有一段 | 隐藏 tab，标题仍显示 |
| 题干中同时有「材料」和「（1）」 | 以第一个 `（1）` 为界，材料取提示句之后全部原文 |
| 材料含 `$` 符号（如价格） | 公式解析要求成对 `$`；单个 `$` 不渲染，按普通文本 |
| 公式语法错误 | 回退 `<code>`，不抛出、不阻塞整题 |
| 公式过长 | 块级公式横向滚动；行内公式允许换行 |
| 草稿时切题 | 立即清空并退出，画布卸载 |
| 草稿时窗口缩放 | ResizeObserver 重设画布，按矢量重绘 |
| 草稿时切换主题 | 颜色随 CSS 变量重绘，笔迹保留 |
| 草稿时打开材料 | 画布高度随题目栏变化重设；材料栏不被覆盖 |
| 触控笔+手掌同时接触 | 仅接受首个 pointerdown 的 pointerId，忽略其他指针 |
| 画布高度为 0（题目折叠） | 不初始化 context；展开后重新 resize |
| 低端设备 DPR > 2 | 上限 2，降低显存与卡顿 |
| 浏览器不支持 Canvas | 隐藏草稿入口，不影响答题 |
| 用户误点「清空」 | 二次确认；确认后不可撤销 |
| 自评弹窗关闭 | 未确认的题目保持原比例，不默认满分 |
| 填空题答案含公式 | 结果页 KaTeX 渲染；自评仍由用户判断 |

## 9. 备选方案与取舍

| 方案 | 放弃原因 |
| --- | --- |
| 材料与题干同栏、用折叠块 | 长材料仍会挤走设问，折叠状态难判断 |
| 材料做成全屏抽屉 | 遮挡题目，无法边读边答 |
| 草稿用独立画板路由 | 破坏阅读连续性，切题成本高 |
| 草稿存 localStorage | 隐私与体积风险；用户明确要求不保存 |
| 草稿画在固定视口层 | 滚动后笔迹与题干错位 |
| 用图片渲染公式 | 不可选中、不可搜索、体积极大 |
| 用 MathJax | 包体与启动成本高于 KaTeX，静态站点收益低 |
| 填空题自动判分 | 数学等价形式太多（`1/2`、`0.5`、`\frac12`），误判率高 |
