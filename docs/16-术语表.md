## 2. 408 学科术语（平台内高频）

### 2.1 数据结构

| 术语 | 简要定义 |
| --- | --- |
| 时间复杂度 | 算法执行步数随规模增长的量级，记 `O(f(n))` |
| 渐进分析 | 关注 n 趋于无穷时的增长阶，忽略常数与低阶项 |
| 栈 / 队列 | 后进先出 / 先进先出的线性结构 |
| 完全二叉树 | 除最后一层外全满，最后一层靠左连续 |
| 平衡因子 | 左右子树高度差，AVL 树要求 ∈ {-1,0,1} |
| 邻接矩阵 / 邻接表 | 图的两种存储：矩阵 O(V²)、表 O(V+E) |
| 最小生成树 | 连通网中边权和最小的生成树（Prim / Kruskal） |
| 拓扑排序 | 有向无环图的线性序，满足所有前驱在前 |
| 散列冲突 | 不同关键字映射到同一地址，用链地址或开放定址处理 |
| B 树 / B+ 树 | 多路平衡查找树，B+ 树数据全在叶层并链式相连 |

### 2.2 计算机组成原理

| 术语 | 简要定义 |
| --- | --- |
| 补码 | 负数表示为模 2ⁿ 的补数，加减统一 |
| 溢出 | 同号相加结果为异号，或异号相减超出范围 |
| CPI | 每条指令平均时钟周期数 |
| 流水线冒险 | 结构 / 数据 / 控制冒险，用停顿、旁路、预测处理 |
| Cache 映射 | 直接、全相联、组相联三种地址映射方式 |
| 写策略 | 写直达（write-through）与写回（write-back） |
| TLB | 页表项的高速缓存，加速虚拟地址转换 |
| 总线仲裁 | 多主设备争用总线时的裁决机制 |
| 中断 | 外部事件打断当前程序，保存现场后转去处理 |
| DMA | 直接存储器访问，不经过 CPU 搬运数据块 |

### 2.3 操作系统

| 术语 | 简要定义 |
| --- | --- |
| 进程 / 线程 | 资源分配单位 / 调度执行单位 |
| 上下文切换 | 保存旧进程现场、恢复新进程现场 |
| 临界区 | 访问共享资源的代码段，需互斥 |
| 死锁四条件 | 互斥、请求与保持、不可剥夺、循环等待 |
| 银行家算法 | 通过安全性检查避免死锁的资源分配策略 |
| 页表 | 虚拟页号到物理页框号的映射表 |
| 缺页中断 | 访问的页不在内存，触发调入 |
| 页面置换 | OPT / FIFO / LRU / Clock 等淘汰策略 |
| 局部性原理 | 时间局部性与空间局部性 |
| 文件索引节点 | inode，记录文件元数据与数据块指针 |
| SPOOLing | 用磁盘缓冲把独占设备改造为共享设备 |

### 2.4 计算机网络

| 术语 | 简要定义 |
| --- | --- |
| OSI 七层 | 物理、数据链路、网络、传输、会话、表示、应用 |
| 封装 / 解封装 | 逐层加头 / 去头的过程 |
| CSMA/CD | 载波监听多路访问 / 冲突检测（以太网） |
| ARP | 由 IP 地址解析 MAC 地址 |
| 路由选择 | 静态路由与 RIP / OSPF / BGP 等动态协议 |
| 三次握手 | SYN → SYN+ACK → ACK，建立 TCP 连接 |
| 四次挥手 | FIN → ACK → FIN → ACK，释放连接 |
| 拥塞控制 | 慢开始、拥塞避免、快重传、快恢复 |
| 流量控制 | 接收方通过窗口字段限制发送速率 |
| CIDR | 无分类域间路由，用前缀长度表示网络 |
| NAT | 网络地址转换，私网地址映射为公网地址 |
