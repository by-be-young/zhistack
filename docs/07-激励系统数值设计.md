# 07 · 激励系统数值设计

## 1. 设计目标

激励系统的任务是**让「今天也学了一会儿」这件事有可见的结算**，而不是把学习变成刷分。三条约束先立：

1. 学习行为本身是主要产出，抽卡只是消费出口，不反向驱动刷题。
2. 任何数值都不奖励「重复刷同一道简单题」。
3. 概率与保底完全公开，抽卡不制造沉没成本焦虑（无付费、无时间限制）。

## 2. 积分产出

### 2.1 答题与交卷

| 行为 | 积分 | 上限/说明 |
| --- | --- | --- |
| 答对 1 题（当日首次遇到该题） | +2 | 同题当日重复作答不计分 |
| 答错 1 题（当日首次遇到该题） | +1 | 鼓励做题，不惩罚错误 |
| 完成一次会话（≥ 10 题） | +10 | 每会话一次 |
| 会话正确率 ≥ 80% | +15 | 与上条叠加 |
| 会话正确率 100% 且题量 ≥ 10 | +30 | 覆盖「≥80%」奖励，不叠加 |
| 错题重练（每题） | +3 | 每日上限 30 |
| 错题出本（答对 2 次） | +10 | 每题仅一次 |
| 首次浏览知识点详情 | +2 | 每知识点一次，日上限 20 |
| 每日首次打开书页跳转 | +3 | 每日一次 |

### 2.2 任务与里程碑

| 行为 | 积分 |
| --- | --- |
| 每日任务（单项） | 20 / 30 / 40（按难度） |
| 每日任务全清 | +30 额外 |
| 每周任务（单项） | 60 / 80 / 120 |
| 连续打卡 7 天 | +50 |
| 连续打卡 14 天 | +120 |
| 连续打卡 30 天 | +300（每 30 天循环，第二次起减半） |
| 集齐一科卡册（集章点亮） | +200（每科一次） |
| 成就解锁 | 30–150（见成就表） |
| 等级提升 | 不返积分，仅解锁展示位 |

### 2.3 日上限与防刷

- 单日积分上限 **300**（不含集章与 30 天里程碑，这两类为一次性）。
- 同一题目在同一自然日内最多贡献 2 分（无论对错）。
- 会话奖励按 `sessionId` 去重，重放存档不重复发放。
- 检测异常：单会话题量 > 60 或用时 < 题量×3 秒，标记 `suspect`，奖励按 50% 发放（仅本地提示，不上报）。

## 3. 积分消耗与抽卡

### 3.1 价格

| 项目 | 价格 | 说明 |
| --- | --- | --- |
| 单抽 | 60 | 必出 1 卡 |
| 十连 | 540 | 9 折，且保底 ≥ 1 张 R |
| 碎片兑换 N 卡 | 30 碎片 | 指定 N 卡 |
| 碎片兑换 R 卡 | 80 碎片 | 指定 R 卡 |
| 重置保底（不提供） | — | 不设计该功能，避免赌博感 |

### 3.2 概率

| 稀有度 | 基础概率 | 保底规则 |
| --- | --- | --- |
| N | 60% | — |
| R | 30% | 十连内前 9 抽无 R+ → 第 10 抽强制 R+ |
| SR | 9% | — |
| SSR | 1% | 累计 90 抽未出 SSR → 第 90 抽强制 SSR |

实现细节：
- 先按概率抽取，再检查保底；保底触发时覆盖结果并清零对应计数。
- `pityR` 只在**十连**语境生效（单抽不享受十连保底）。
- SSR 保底计数跨卡池共享（v1.0 只有一个池）。
- 概率公示固定展示在抽卡页，不可折叠隐藏。

### 3.3 期望与节奏

单抽期望稀有度价值（按碎片折算）：

```
E = 0.60×5 + 0.30×15 + 0.09×40 + 0.01×100 = 3 + 4.5 + 3.6 + 1 = 12.1 碎片/抽
```

按日均 150 积分计，日均可抽 2.5 次，约 30 碎片 → 平均 10 天可兑换 1 张 R 卡。首月可集齐约 25–30 张卡（全池 48–64 张），节奏为「一个月看到册子填满一半」。

### 3.4 重复卡处理

| 稀有度 | 转碎片 | 说明 |
| --- | --- | --- |
| N | 5 | 新卡不转碎片，直接入库 |
| R | 15 | 同上 |
| SR | 40 | 重复 3 次以上额外 +10（「溢出补偿」） |
| SSR | 100 | 重复即满额碎片，不设额外 |

### 3.5 抽卡历史

保留最近 50 条，字段：时间、卡 id、稀有度、是否重复、触发保底标记。用于自证概率与复盘。

## 4. 等级

| 等级 | 累计积分阈值 | 解锁 |
| --- | --- | --- |
| Lv.1 起步 | 0 | 基础功能 |
| Lv.2 上路 | 300 | 卡册筛选 |
| Lv.3 稳行 | 800 | 自定义题量至 40 |
| Lv.4 熟手 | 1600 | 统计页 90 天视图 |
| Lv.5 老练 | 2800 | 自定义题量至 60 |
| Lv.6 精研 | 4500 | 十连额外 1 张保底（仅展示，实际已含） |
| Lv.7 通透 | 7000 | 集章页展示「全科进度」 |
| Lv.8 案头 | 10000 | 无（荣誉位） |

等级只升不降；阈值固定写死在 `core/levels.js`，不随存档变化。

## 5. 连续打卡

- 判定：本地日（04:00 分界）内完成 ≥ 1 道题即打卡。
- `current`：若昨日有打卡则 +1，否则重置为 1；跨日首次作答时结算。
- `longest`：取历史最大值。
- 补签：不提供。断签后 `current` 归 1，`longest` 保留。
- 里程碑奖励在达标当日一次性发放，`milestoneLog` 记录已发节点，防重复。

## 6. 连击（会话内）

| 连击 | 反馈 | 额外积分 |
| --- | --- | --- |
| 3 | 顶部细条显示「3 连」 | +1 |
| 5 | 「5 连·稳住」 | +3 |
| 8 | 「8 连·手感在」 | +6 |
| 12 | 「12 连·状态极佳」 | +10 |

- 只在会话内累计，答错或交卷清零。
- 额外积分单会话上限 +20。
- 反馈不遮挡题干，不弹窗，只在顶部状态条出现 1.2 s。

## 8. 经济平衡校验

按「中等强度学习者」建模：每日 1 套 20 题（正确率 70%）+ 2 个知识点 + 3 道错题。

| 来源 | 每日积分 |
| --- | --- |
| 答题（10 对 + 4 错） | 20 + 4 ≈ 24（当日首遇计分） |
| 会话完成 + 正确率 ≥ 80% 未达 | 10 |
| 任务（4 项 + 全清） | 100 + 30 |
| 错题重练 3 题 | 9 |
| 知识点 2 个 | 4 |
| 连击 | 约 5 |
| **合计** | **≈ 182** |

消耗：每日 3 抽（180）。结论：**收支基本平衡，抽卡不会挤占学习动力，也不会无限积累**。高强度日（300 上限）可多抽 2 次，属于合理奖励。

## 9. 展示规则

- 积分变化不逐条弹 Toast，只在会话结束的结算卡上汇总一行「+34 积分（答题 20 / 正确率 14）」。
- 抽卡结果与积分扣减在同一屏完成，避免「先扣后抽」的焦虑感。
- 卡册与集章纯展示，不设「限时卡池」与倒计时（不制造稀缺焦虑）。
- 所有概率、保底状态、抽卡历史在抽卡页可查。

## 10. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 积分流水与余额不一致 | 以流水重算；差异 > 0 时提示「已按流水校准」 |
| 同一会话重复提交 | 按 `sessionId` 幂等，第二次不发放 |
| 修改系统时间刷打卡 | 以 `lastDate` 比较，未来日期拒绝；连续 3 次异常日期提示校准系统时间 |
| 导入存档携带超上限积分 | 接受导入值，但当日新增积分按上限截断 |
| 卡池数据更新删卡 | 已获得卡保留在卡册（`retired` 标记），不再出现在新抽卡结果 |
| 保底计数与历史不一致 | 以 `pitySsr` 为准，历史仅展示 |
