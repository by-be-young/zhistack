# 08 · 薄弱知识点诊断与推荐算法

## 1. 问题定义

「薄弱」不是感觉，是可复核的结论。系统要在**样本很少**的现实条件下（很多知识点只做过 1–3 题）给出稳定、可解释的排序，并且明确告诉用户「为什么推荐这个」。

三个难点：
1. **样本稀疏**：1 题答错不能判定该知识点薄弱，可能只是审题失误。
2. **近因偏差**：三个月前的错误与昨天的错误，权重不应相同。
3. **状态混杂**：错题「已出本」不应继续按错误次数惩罚。

## 2. 掌握度模型

### 2.1 输入

每个知识点 `k` 的原料（来自存档）：

| 符号 | 含义 | 来源 |
| --- | --- | --- |
| `a` | 累计作答次数（该知识点所有题） | `knowledge[k].attempts` |
| `c` | 累计全对次数 | `knowledge[k].correct` |
| `t_last` | 最近一次作答时间 | `knowledge[k].lastAt` |
| `m_w` | 未出本错题数 | `mistakes` 中该知识点的题，`stage != mastered` |
| `m_c` | 已出本错题数 | `stage == mastered` |
| `manual` | 用户手动标注（掌握 / 需复习 / 无） | `knowledge[k].manual` |
| `v` | 知识点浏览次数（弱信号） | `knowledge[k].views` |

### 2.2 公式

```
accS     = (c + 1) / (a + 2)              // Laplace 平滑，a=0 时 0.5 中性
recencyS = exp(-Δdays / 21)               // 21 天半衰期≈0.36；Δdays 取整
mistakeS = 1 / (1 + 0.8·m_w)              // 未出本错题惩罚
coverS   = min(1, (a + 0.5·v) / 4)        // 覆盖度：做过 + 看过
confidence = 0.4 + 0.6·min(1, a/6)        // 置信度乘子，样本少则整体收敛到中值

base = 0.58·accS + 0.22·recencyS + 0.12·mistakeS + 0.08·coverS
mastery = round(100 · base · confidence + 100 · base · (1-confidence) · 0.55)
```

最后一项的含义：样本不足时，把结果向 55 分收缩（「未知偏中性」），避免 1 题答错就判 20 分。

手动标注覆盖：`manual === 'mastered'` → `mastery = max(mastery, 85)`；`manual === 'review'` → `mastery = min(mastery, 45)`。手动结果在 UI 上标注「手动」，与自动值同时展示。

### 2.3 档位

| 档位 | 条件 | 展示 |
| --- | --- | --- |
| 未练 | `a = 0` 且 `v = 0` | 「未练」（不打分） |
| 薄弱 | `mastery < 45` 且 `a ≥ 2` | 玫瑰色档位 + 分值 |
| 待巩固 | `45 ≤ mastery < 75` | 琥珀档位 |
| 稳固 | `mastery ≥ 75` 且 `a ≥ 3` | 薄荷档位 |
| 样本少 | `a < 2` 且 `v > 0` | 「样本少」+ 分值（灰） |

## 3. 薄弱评分与排序

掌握度描述「当前水平」，薄弱评分描述「此刻最该练的优先级」：

```
weakness = (100 - mastery)
         × (0.6 + 0.4·min(1, a/4))          // 有样本才更可信地「薄弱」
         + 12·min(3, m_w)                    // 未出本错题加成，最多 +36
         + 8·最近错误衰减加成                 // 近 3 天错 → +8；7 天 → +4；14 天 → +2
         - 15·(近期已推荐且未练)               // 去重惩罚，24h 内
```

推荐条件（全部满足才入榜）：
1. `mastery < 75`（已稳固不推）
2. `a ≥ 1` 或 `v ≥ 1`（完全没接触过的走冷启动路径）
3. 该知识点可用题量 ≥ 3（保证能组出小卷）
4. 24 小时内未被推荐过（除非用户点「换一批」）

排序：`weakness` 降序；同分按 `m_w` 降序，再按 `t_last` 升序（越久没练越前）。

### 3.1 推荐理由生成

每条推荐必须带 2–4 条可核对理由，模板：

| 条件 | 文案 |
| --- | --- |
| `accRate < 0.6` 且 `a ≥ 3` | 「正确率 43%（7 题对 3）」 |
| `m_w ≥ 1` | 「有 2 道错题未出本」 |
| `Δdays ≥ 14` | 「已 21 天未练」 |
| `a == 1` | 「只练过 1 题，样本不足」 |
| 同章其他知识点稳固 | 「同章其他考点已稳固，本点是短板」 |
| 覆盖题量 | 「可抽 8 题专项」 |

理由最多 4 条，按上表顺序取，数字实时计算。

## 4. 专项练习生成

点击「针对练习」时：

```
1. 目标知识点 K（可多选，最多 3 个）
2. 题池 = 题 ∩ K 的题
3. 若 |题池| < 5 → 加入同章节的其他知识点题目（标注「同章补充」）
4. 题量 = clamp(5, |题池|, 15)
5. 难度配比按该知识点历史错误率调整：
   - 错误率 > 50% → 基础 60% / 进阶 30% / 综合 10%（先稳住）
   - 否则 40/40/20
6. 生成会话（mode = 'weak'），记录 originKnowledge: K[]
```

结果页额外展示「本次专项前后掌握度变化」（提交时快照 vs 提交后重算）。

## 5. 冷启动策略

无任何答题记录时，推荐不走薄弱排行，改走**章节权重路径**：

```
章节权重 = 该章题量 × 难度均值 × 科目权重
科目权重 = { ds: 1.0, co: 0.95, os: 0.95, cn: 0.9 }   // 408 分值占比近似
```

输出「起步三件事」：
1. 建议先做 10 题「数据结构 · 基础」摸底（判断整体水平）。
2. 推荐 1 个入门知识点（章节权重最高的章的首个基础点）。
3. 引导挂载教材 PDF（可选，不阻塞）。

首日结束后（有 ≥ 10 题记录）自动切换到薄弱排行，并保留「摸底未完成」提示直到各科各做过 ≥ 5 题。

## 6. 科目级诊断

```
subjectMastery = Σ(knowledgeMastery × weight_k) / Σ(weight_k)
weight_k = min(3, 题量_k) + 1
```

同时输出：
- 题量与正确率（原始数据）。
- 近 7 天趋势（本周 mastery − 上周 mastery），用于判断「在进步还是在退步」。
- 错题密度（未出本错题 / 题量）。

## 7. 统计口径一致性

| 场景 | 口径 |
| --- | --- |
| 掌握度 | 全对才算「对」，漏选半分不计入 `correct` |
| 正确率（展示） | `c / a`，展示为整数百分比 |
| 会话正确率 | 全对题数 / 题量 |
| 薄弱排行 | 用掌握度 + 错题状态，不用单次会话正确率 |
| 趋势 | 周对周比较，样本 < 10 题标「样本少」 |

## 8. 边界情况

| 场景 | 处理 |
| --- | --- |
| 知识点只有 1 题且答错 | 掌握度被 confidence 收缩，不会直接判 20 分；推荐里标「样本少」 |
| 所有知识点都稳固 | 排行显示「暂无薄弱点」，给「挑战高难」入口（综合难度题） |
| 题量不足 3 的知识点 | 不进入排行，改为「补题建议」列表 |
| 用户手动把某点标为掌握 | 排行降权但若错题未出本仍提示「错题未清」 |
| 数据刚清空 | 回到冷启动路径，不显示空排行 |
| 时间回拨 | `Δdays < 0` 按 0 处理，`recencyS = 1`，并在设置页提示时间异常 |
| 同一知识点 24h 内重复推荐 | 除非用户点「换一批」，否则降权 -15 |
| 已出本错题再次答错 | `m_w` +1（回炉），掌握度下降，排行上升，附「回炉」标签 |

## 9. 算法可测试性

`core/mastery.js` 与 `core/diagnose.js` 为纯函数，输入 `{attempts, correct, lastAt, mistakes, manual}` 与 `knowledge[]`，输出数值与排序。测试用固定数据构造期望值（见 11-测试方案 `TC-ALG-*`），任何公式调整必须同步更新测试基线。

## 10. 可视化

- 知识点详情：环形掌握度 + 四要素拆解（正确率 / 近因 / 错题 / 覆盖）条形图，让用户看懂分数来源。
- 首页薄弱卡：分值 + 3 条理由 + 一键练习。
- 统计页雷达：各科掌握度，轴数随科目数动态生成（当前 7 轴），轴标签带分值；无数据轴显示虚线基准 50。
