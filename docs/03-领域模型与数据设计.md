# 03 · 领域模型与数据设计

## 1. 实体关系

```
科目 Subject ─┬─ 书目 Book ── 章节 Chapter ── 知识点 Knowledge
              │                                  │
              │                                  ├─ 题目 Question
              │                                  ├─ 知识卡 Card
              │                                  └─ 答题明细 Attempt
              │
              └─ 练习会话 Session ── 答题明细 Attempt
                                     │
                                     ├─ 错题条目 Mistake
                                     └─ 日度聚合 DailyStat

任务 TaskDef ── 任务实例 TaskState（按日/周）
积分流水 PointLog ── 等级 Level
知识卡 Card ── 卡册 Owned / 碎片 Shard / 集章 Stamp
```

静态实体（科目、书目、章节、知识点、题目、卡池、任务定义）在构建期固定；动态实体（会话、答题明细、错题、卡册、任务状态、流水）在运行期写入存档。

## 2. 静态数据模型

### 2.1 科目 `Subject`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | `ds` `co` `os` `cn` |
| `name` | string | 是 | 数据结构 / 计算机组成原理 / 操作系统 / 计算机网络 |
| `short` | string | 是 | DS / CO / OS / CN |
| `accent` | string | 是 | 科目强调色（令牌名，不用裸色值） |
| `order` | number | 是 | 展示顺序 1–4 |

### 2.2 书目 `Book` 与章节 `Chapter`

| 字段（Book） | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `book-ds-wangdao` 形式 |
| `title` / `author` / `edition` / `publisher` | string | 公开出版信息 |
| `subject` | string | 科目 id |
| `pages` | number | 总页数（印刷页） |
| `note` | string | 使用提示（如「页码为印刷页」） |
| `chapters` | Chapter[] | 两级树 |

| 字段（Chapter） | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `ds-ch3` / `ds-ch3-2` |
| `title` | string | 章或节标题 |
| `page` | number | 该节点起始印刷页 |
| `children` | Chapter[] | 仅章级有 |

约束：同科目下 `chapter.id` 唯一；`page` 单调不减；章必须至少含 1 个知识点或 1 道题，否则视为索引缺口并在校验中告警。

### 2.3 知识点 `Knowledge`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | `k-ds-012` 全局唯一 |
| `subject` | string | 是 | 科目 id |
| `chapterId` | string | 是 | 归属章节（可指向节） |
| `gid` | string | 是 | 考点编号 `DS-3.2-04`，跨书对齐 |
| `title` | string | 是 | 8–24 字 |
| `difficulty` | 1\|2\|3 | 是 | 基础 / 进阶 / 综合 |
| `tags` | string[] | 是 | 1–5 个，用于检索与推荐 |
| `summary` | string | 是 | 40–80 字概括，检索与卡片正文 |
| `points` | string[] | 是 | 3–6 条要点，支持 `**粗体**` 与行内反引号 |
| `pitfalls` | string[] | 否 | 0–3 条易错点 |
| `bookRefs` | `{bookId, chapterId, page}[]` | 是 | 至少 1 条书页映射 |
| `related` | string[] | 否 | 相关知识点 id（同章默认补齐） |
| `estMin` | number | 否 | 建议学习分钟数，用于任务与计划 |

校验规则：`bookRefs` 的 `bookId/chapterId` 必须存在；`related` 不得自引用且必须存在；`points` 不少于 3 条。

### 2.4 题目 `Question`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | `q-ds-0001` |
| `subject` | string | 是 | 科目 |
| `knowledgeId` | string | 是 | 主考点（唯一） |
| `type` | `single`\|`multiple`\|`judge` | 是 | 单选 / 多选 / 判断 |
| `stem` | string | 是 | 题干，支持行内标记 |
| `options` | `{key,text}[]` | 是 | single/multiple 为 4 项；judge 由渲染层生成「正确/错误」 |
| `answer` | string[] | 是 | single/judge 长度 1；multiple ≥ 2 |
| `explain` | string | 是 | 解析 60–200 字，说明为什么错 |
| `difficulty` | 1\|2\|3 | 是 | 难度 |
| `source` | `original`\|`adapted`\|`real` | 否 | 可选标记：自编 / 改写 / 原卷 |
| `year` | number | 条件 | `adapted` 必填（考点年份映射） |
| `tags` | string[] | 否 | 辅助筛选 |

约束：`answer` 的 key 必须全部存在于 `options`；`multiple` 至少 2 个正确项且不得全选；题干不得重复（校验器做去重告警）。

### 2.5 知识卡 `Card`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `c-ds-01` |
| `name` | string | 4–8 字卡名，如「页表之眼」 |
| `subject` | string | 科目 |
| `rarity` | `N`\|`R`\|`SR`\|`SSR` | 稀有度 |
| `knowledgeId` | string | 绑定知识点 |
| `line` | string | 卡面一句话（12–26 字） |
| `motif` | string | 纹样标识：`grid` `orbit` `wave` `circuit` `lattice` `stack` |
| `quote` | string | 背面考点提示（可空） |

卡池约束：每科 ≥ 12 张；每科至少 1 张 SSR 与 2 张 SR；全池 SSR 占比 ≤ 15%（实际由稀有度概率控制）。

### 2.6 任务定义 `TaskDef`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | `t-daily-answer` |
| `cycle` | `daily`\|`weekly`\|`achievement` | 周期 |
| `title` / `desc` | string | 展示文案 |
| `metric` | 枚举 | `answered` `correct` `mistakeReview` `knowledgeView` `paperDone` `streak` `mistakeCleared` `masteryCount` `sessionScore` |
| `target` | number | 目标值 |
| `reward` | number | 积分奖励 |
| `icon` | string | 图标标识（内置 SVG 名） |

### 3.2 各实体规则

| 实体 | 关键规则 |
| --- | --- |
| `profile.pointLog` | 保留最近 300 条；`points` 与流水和不一致时以流水重算并提示 |
| `knowledge[x]` | `attempts/correct` 单调累加；`lastAt` 取最大值；`manual` 仅由用户设置 |
| `mistakes[qid]` | `count` 累加；`rightStreak` 答对 +1、答错归零；`rightStreak ≥ 2` → `mastered` 并写 `releasedAt` |
| `cards.pitySsr/pityR` | 每抽 +1，出对应稀有度归零；保底触发条件见 07 |
| `tasks` | 跨日/跨周重建，未领取的历史进度丢弃（不补发），已领取记录保留 7 天用于回看 |
| `sessions` | 上限 500 条，按 `endedAt` 淘汰；聚合量由 `daily` 单独保存避免全量遍历 |
| `draft` | 单条；24 h 过期；交卷或放弃后清空 |

### 3.3 日期口径

全系统「日」以本地时间 **04:00** 为分界（与个人活动日志口径一致）：`2026-11-26 04:00` 至 `2026-11-27 03:59` 记为 `2026-11-26`。周以周一 04:00 起算，ISO 周编号。实现函数 `dayKey(date)` 与 `weekKey(date)` 集中在 `core/time.js`，禁止各页面自行取日期。

## 4. 索引与派生结构（运行时）

| 结构 | 内容 | 构建时机 |
| --- | --- | --- |
| `knowledgeById` / `questionById` / `cardById` | Map 查找 | 数据模块加载 |
| `questionsByKnowledge` | 知识点 → 题 id 列表 | 加载 |
| `knowledgeByChapter` | 章节 → 知识点 | 加载 |
| `searchIndex` | 每条知识点的 token 集合 + 字段权重向量 | 加载（lazy，首次检索时构建） |
| `mistakeRank` | 错题的 `count × 近因` 排序缓存 | 进入错题页/诊断页时计算 |
| `masteryMap` | 知识点掌握度 | 首页/诊断/统计按需重算 |

## 5. 状态机

### 5.1 错题状态

```
       答错                 答对 1 次               答对 2 次
  ──► new ──────────────► reviewing ──────────────► mastered（出本）
       ▲                     │                        │
       └────── 再次答错 ◄────┘        手动恢复 ◄───────┘
```

- `mastered` 后 30 天内再次答错 → 回到 `new` 并告警「已出本题目回炉」。
- 手动移除写入 `releasedAt`，保留历史，不参与排行。

### 5.2 练习会话状态

```
created ──► answering ──┬──► submitted（已评分）
                        ├──► expired（超时自动交卷）
                        └──► abandoned（主动放弃，草稿清除）
```

`submitted` 之后只读，复盘不改变答案；重练生成新会话。

### 5.3 抽卡保底

```
每次抽卡：pitySsr+1, pityR+1
若 rarity == SSR → pitySsr=0
若 rarity >= R   → pityR=0
若 pitySsr == 90 → 强制 SSR
若 tenPull 且前 9 抽无 R+ → 第 10 抽强制 R+
```

## 6. 迁移策略

| 版本 | 变更 | 迁移动作 |
| --- | --- | --- |
| v1 | 初版存档 | — |
| v2 | 增加 `cards` 与 `tasks`、`draft` | v1 → v2：补空对象，重算等级与连击 |

规则：
1. 读取时若 `schemaVersion < 当前`，按顺序执行迁移函数链，迁移前先备份原档。
2. `schemaVersion > 当前` 拒绝加载，提示「存档来自更新版本」并给导出入口。
3. 迁移失败不覆盖原档，只读降级并提示导出。
4. 每次迁移写 `migrationLog`（版本、时间、结果），保留在存档内便于排查。

## 8. 数据校验（构建期）

`scripts/validate-data.mjs` 在 `prebuild` 执行，任一硬错误则构建失败：

1. 主键唯一（知识点、题目、卡、章节、书目）。
2. 引用完整：题目 `knowledgeId`、知识点 `chapterId`、卡 `knowledgeId`、`related`、`bookRefs`。
3. 枚举合法（科目、题型、稀有度、难度）。
4. 答案合法（key 存在、多选 ≥ 2 且不全选、判断题答案在 `T/F`）。
5. 文本规范：无空字段、长度在区间内、不得出现未闭合的行内标记。
6. 分布检查：七科知识点与题目数量均衡（各 ≥ 20 题、≥ 20 知识点为硬线），每科卡 ≥ 12 张。
7. 题干预重复（相似度 > 0.9 视为疑似重复并告警）。

告警（warning）不阻断构建，但输出清单，发布前需人工确认。
