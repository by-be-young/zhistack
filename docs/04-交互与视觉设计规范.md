# 04 · 交互与视觉设计规范

## 1. 设计理念

**工业薄雾（Industrial Mist）**：把工科的秩序感（网格、刻度、等宽标注、硬边卡片）与备考的情绪需求（柔和、留白、可呼吸）叠在一起。界面像一张精密仪表盘，但底色不冷硬——用低饱和马卡龙色做状态与奖励，只在需要被看见的地方亮。

三条准则：
1. **结构先于装饰**：先让用户看清「在哪、剩多少、下一步做什么」，再谈氛围。
2. **一屏一个主动作**：每页只有一个视觉上最重的按钮，其余降级为描边或文字按钮。
3. **奖励克制**：抽卡与集章是收尾的仪式，不进入答题主流程，不遮挡题干。

## 3. 字体与排版

```
--font-sans: "Source Han Sans SC", "Noto Sans SC", "PingFang SC",
             "Microsoft YaHei", system-ui, sans-serif;
--font-mono: ui-monospace, "SFMono-Regular", "JetBrains Mono",
             "Cascadia Code", Consolas, monospace;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 40 / 1.15 | 650 | 首页主标题、大数字 |
| H1 | 28 / 1.25 | 600 | 页面标题 |
| H2 | 20 / 1.4 | 600 | 区块标题 |
| H3 | 16 / 1.5 | 600 | 卡片标题 |
| Body | 14.5 / 1.75 | 400 | 正文、题干 |
| Small | 13 / 1.6 | 400 | 说明、元信息 |
| Label | 11 / 1.2 | 500 | 等宽标签，`letter-spacing: 0.08em`，`text-transform: uppercase` |
| Num | 与 Display 同 | 600 | 数字使用 `font-variant-numeric: tabular-nums` |

规则：
- 中文正文不用 500 以下字重，避免细体发虚。
- 等宽只用于编号、页码、计时、题干中的公式与代码。
- 标题字距 `-0.01em`，正文 0；等宽标签 +0.08em。
- 段落最大行长 42 个汉字（约 `68ch`），超过则加宽容器或分栏。

### 3.1 正文阅读层（资料库 / 书库 / 材料栏 / 知识点）

长文阅读页不复用 UI 排版，另起一层 `--doc-*` 令牌（`src/styles/tokens.css`），排版规则集中在 `src/styles/notes.css`，渲染前处理在 `src/core/reading.js`。骨架参考 YoungBlog 文章详情页，色号按本站深色「工业薄雾」体系重调。

#### 3.1.1 分层与单一来源

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 令牌 | `tokens.css` | `--doc-*` 深浅两套色值、`--font-read` / `--font-display` |
| 规则 | `notes.css` | `.note-body` 下全部正文元素（标题、段落、表格、代码、提示块、书库语义块） |
| 预处理 | `reading.js` | 标题层级归一、表格包裹 `.doc-table`、深色代码配色映射、主题切换重渲染 |
| 页面 | `NoteDetail.vue` / `BookReader.vue` / `MaterialPane.vue` | 只负责页框：目录、元信息条、翻页器、字号控件；**不得**重定义正文元素的字体、字号、底色、边框、对齐 |

同一元素在资料库与书库必须得到同一套视觉：书库不是另一种文章，只是容器不同。

#### 3.1.2 字体

| 用途 | 令牌 | 字体栈 |
| --- | --- | --- |
| 标题 | `--font-display` | `CangErJinKai`（仓耳今楷 01 W04 子集，约 2 MB）→ `Source Han Sans SC` → `PingFang SC` → `Microsoft YaHei` |
| 正文 | `--font-read` | `Times New Roman` → `Source Han Serif SC` → `Noto Serif SC` → `Songti SC` → `SimSun` → serif |
| 代码、编号、页码 | `--font-mono` | 见 §3 主表 |
| UI（目录、按钮、元信息） | `--font-sans` | 见 §3 主表 |

规则：
- 标题一律 `font-weight: 400` + `font-synthesis: none`。仓耳今楷只有一档字重，浏览器伪粗体会把笔画糊成墨团。
- 阅读层正文允许 400 字重（衬线自带实体笔画），但不得低于 15 px；UI 层仍遵守「中文不用 500 以下」。
- 标题子集由 `scripts/build-heading-font.py` 生成，字符集 = GB2312 + 全站标题实际用字（当前 533 字，缺失 0）。新增书目或标题后必须重跑，否则回退到无衬线，层级会突然变样。

#### 3.1.3 标题：h1 为顶层

数据层（Docsy 导出、markdown 书）的标题可能从 h3 起跳，`reading.js` 在渲染前把最小层级整体上提为 h1，偏移量同步给目录，因此**视觉层级永远从 h1 开始**。Markdown 书稿第一行必须是 `# 一级标题`。

| 层级 | 字号 | 行高 | 内边距 | 色条 | 底色 | 文字色 | 圆角 | 上 / 下间距 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| h1 | `1.5em` | 1.42 | `.62em 1.05em` | 左 5 px `--doc-h1-bar` | 蓝渐变，72% 处透明 | `--doc-h1-text` | 12 px | `1.55em / .8em` |
| h2 | `1.24em` | 1.45 | `.58em 1em` | 左 4 px | 绿渐变，74% | `--doc-h2-text` | 10 px | `1.35em / .7em` |
| h3 | `1.08em` | 1.5 | `.52em .95em` | 左 4 px | 橙渐变，76% | `--doc-h3-text` | 10 px | `1.3em / .65em` |
| h4 | `1em` | 1.5 | `.46em .9em` | 左 3 px + 26% 描边 | 紫 16% 平铺 | `--doc-h4-text` | 8 px | `1.1em / .6em` |
| h5 / h6 | `.95em` / `.9em` | 1.55 | 无 | 无 | 无 | `--doc-ink` / `--doc-ink-soft` | — | 不铺色 |

- 色序固定：**蓝 → 绿 → 橙 → 紫**，不随科目色变化；科目色只用于页框标签（§2.3）。
- 正文首块标题 `margin-top: .2em`，避免卡片顶部空一大截。
- 标题内允许行内代码、公式；禁止在标题里塞按钮、标签页、卡片。
- `scroll-margin-top: 84–88px`，保证目录跳转不被顶栏压住。

#### 3.1.4 正文块

| 元素 | 规格 |
| --- | --- |
| 根字号 | 15.5 px（桌面）/ 15 px（≤900）/ 14.8 px（≤700）；书库由内层 `style` 覆盖为 14–22 px |
| `p` | `margin: .85em 0`；`text-wrap: pretty`；**禁止 `text-align: justify`**（中文两端对齐会出现大片字距空洞） |
| `strong` | `--doc-strong`，700 |
| `em` | 只换色为 `--lilac`，`font-style: normal`，不加下划线 |
| `a` | `--mint`，1 px 下划线、38% 透明、`offset 3px`；hover 转 `--mint-deep` |
| `ul` / `ol` | 缩进 1.4em / 1.7em；`li` 行高 1.85、间距 .3em；无序 marker 用 `--doc-h2-bar`，有序序号用 `--doc-h1-bar` + `tabular-nums` |
| `hr` | 宽 `min(100%, 420px)`、居中、渐变细线 + 中心 0.42em 琥珀菱形 |
| `.pgmark` | 页码标记，mono `.66em`，右对齐弱色 |

行长：`.note-body` 最大 880 px（约 56 汉字）。超过时加宽容器不加字号。

#### 3.1.5 引用与提示块

- `blockquote`：1 px `--doc-rule` 描边 + 10 px 圆角 + 卡片底；左侧 3 px **玫 → 薄荷 → 琥珀**三段渐变竖条（上下各留 12 px），透明度 0.75；首段 `strong` 用 `--amber`。
- `.tip` / `.region`：琥珀系提示块，`1px 26% 描边 + 6% 底 + 3px 实条 + 8–10px 圆角`；标题行用 10% 底、600 字重；正文继承 `--doc-ink-soft`。
- 不允许整块高饱和铺底，不允许左侧竖条与描边不同色系混用。

#### 3.1.6 表格

| 项 | 规格 |
| --- | --- |
| 容器 | 统一由 `reading.js` 包 `.doc-table`：1 px 描边、10 px 圆角、`--bg-1` 底、`overflow-x: auto`、7 px 细滚动条 |
| 网格 | **无竖线**，只有 `--doc-rule` 横线；`border-collapse: separate`，`border-spacing: 0` |
| 表头 | `--font-display`、400、`.96em`、`letter-spacing .02em`、`--doc-table-head` 底、下边线加深、不换行 |
| 斑马 | `tbody tr:nth-child(even)` → `--doc-table-zebra`；hover → `--doc-table-hover` |
| 首列 | `--doc-table-first`、600，作为行标题 |
| 单元格 | `padding: .6em .95em`，`text-align: left`，`vertical-align: top`，允许换行 |
| 题注 | `caption` 用 sans `.78em`、左对齐、`--doc-ink-faint` |
| 移动端 | 表格字号 `.88em`、padding 收到 `.5em .7em`；只允许表格内部横滚，页面不得横向溢出 |

禁止：`border: 1px solid` 全网格、`border-collapse: collapse` 的旧表样式、给表格加整块高亮底。

网格子项（`.reader-grid > *`、`.reader-main`、`.note-body`）必须写 `min-width: 0`；否则表头 `nowrap` 的宽表会按 min-content 撑破栅格，让整页横向溢出。

#### 3.1.7 代码与公式

- 行内 `code`：mono `.86em`、`--doc-mark` 底、5 px 圆角、mint 文字。
- 代码块：10 px 圆角、1 px `--doc-code-line`、`--doc-code-bg` 底、`.82em`、行高 1.72、`tab-size 4`、内部横滚。
- 深色主题下源码里写死的浅色行内色（`#8f5902` 等）由 `DARK_SYNTAX` 映射为同色系亮色；映射表新增条目时保持「注释灰绿、关键字蓝、字符串绿、错误红」的语义不变。
- `katex` 统一 `1.03em`；`katex-display` 上下 1em、可横向滚动。

#### 3.1.8 图片与图示

| 项 | 规格 |
| --- | --- |
| `img` | 6 px 内边距 + 1 px `--doc-rule-mid` + 12 px 圆角 + `--bg-2` 底 + 轻投影，居中 |
| `figure` / `.figure` | 12 px 内边距卡片，图片去掉自身描边；题注 `.78em`、sans、居中、`--doc-ink-faint` |
| `.fig`（书库图示） | 1 px 虚线框 + 8 px 圆角 + `--bg-2` 底；`.fig-body` 用 mono `.8em` 呈现「主项 ｜ 分支」文字图 |
| 失败占位 | 保留 alt 文案，不显示破图边框 |

#### 3.1.9 书库专用（`BookReader.vue`）

| 项 | 规格 |
| --- | --- |
| 节标题 | 即 h1，与资料库**完全同规格**（彩底 + 色条）；不得改成「无底 + 竖线」 |
| 节内小节 | h2（绿）、编号小标题 h3（橙） |
| 字号缩放 | 14–22 px，写在 `.note-body` 内层 `style`；正文、标题、间距全部 em，随缩放等比变化 |
| 页框 | 元信息条、CONTENTS 目录、翻页器、本节目录用 UI 层（sans、`--text-2/3`、12–12.5 px） |
| Markdown 语义块 | `p.tag`（考纲标签）sans `.76em` + 字距 `.08em` + amber；`p.item` 600；`p.li` 前置圆点；`p.formula` mono `.9em` 底块；`sup` `.68em` |
| 禁止 | 在 `BookReader` 的 `:deep()` 里覆写 h1–h6 / p / blockquote / hr / a / table / th / td —— 2026-11 曾因这组覆写让书库退回旧样式，与资料库割裂 |

#### 3.1.10 验收清单

- 深 / 浅两套主题各截一张资料库页、一张书库页，同层级元素可逐项对齐（色条宽、内边距、圆角、字号比例一致）。
- 标题对比度 ≥ 3:1，正文 ≥ 4.5:1（`--doc-ink` 对 `--bg-1`）。
- 390 / 768 / 1440 三档无页面级横向溢出；宽表只在 `.doc-table` 内滚动。
- 书库字号 14 / 16 / 18 / 22 px 四档下，标题与正文比例不变、无换行塌陷。
- `npm run build` 通过；新增标题字后重跑 `scripts/build-heading-font.py` 并复核缺失字数。

## 4. 间距、圆角、描边、阴影

| 项 | 规格 |
| --- | --- |
| 间距基数 | 4 px；使用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 圆角 | 卡片 14 px；小组件 10 px；胶囊 999 px；内嵌块 8 px |
| 描边 | 默认 1 px `--line`；激活 1 px `--line-strong`；不使用粗描边 |
| 阴影 | 深色下不用投影，用「内高光」：`inset 0 1px 0 rgba(255,255,255,0.04)`；悬浮层用 `0 18px 48px rgba(0,0,0,0.45)` |
| 网格背景 | `repeating-linear-gradient` 32 px，透明度 0.035（深）/0.05（浅），仅页面底层 |
| 焦点环 | `0 0 0 2px var(--bg-0), 0 0 0 4px var(--mint)` |
| 最大内容宽 | 1280 px；左右安全边距 24（桌面）/16（移动） |

## 5. 动效

| 场景 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| 悬浮、按压 | 120 ms | `ease-out` | `translateY(-1px)`，不做放大 |
| 页面切换 | 200 ms | `cubic-bezier(.2,.8,.2,1)` | 淡入 + 上移 8 px |
| 弹层出现 | 240 ms | 同上 | 遮罩淡入，面板 0.96 → 1 |
| 抽卡揭晓 | 520 ms | `cubic-bezier(.16,1,.3,1)` | 卡面翻转 + 光晕扩散，只播一次 |
| SSR 光效 | 2400 ms 循环 | `linear` | 渐变扫光，`prefers-reduced-motion` 下静止 |
| 进度变化 | 320 ms | `ease-out` | 数值与环形同步 |
| Toast | 停留 2.4 s | 进出 180 ms | 顶部居中，最多堆叠 3 条 |

禁止：无限弹跳、无意义的位移动画、超过 600 ms 的阻塞式动效、抽卡过程中的强制等待（可点击跳过）。

```
│ Header：面包屑 · 当前科目过滤 · 积分 · 连击 · 主题 · 设置      │ 56px
├──────────┬──────────────────────────────────────────────────┤
│ NavRail  │  主内容区（max 1280，12 栅格，gutter 24）           │
│ 72px     │                                                  │
│ 图标 +    │  ┌───────────────┐ ┌───────────────┐             │
│ 竖排中文  │  │ 卡片 A (7col)  │ │ 卡片 B (5col) │             │
│          │  └───────────────┘ └───────────────┘             │
└──────────┴──────────────────────────────────────────────────┘
```

- NavRail 固定左侧，条目：总览 / 书库 / 知识点 / 练习 / 错题 / 卡册 / 任务 / 统计。当前项左侧 2 px 薄荷竖条 + 图标提亮。
- 移动端（< 900 px）NavRail 收起为底部 5 项快捷栏（总览 / 练习 / 错题 / 卡册 / 更多），其余进抽屉。
- 首页栅格：左 7 列「今日主线」（继续学习卡 + 薄弱点 3 条），右 5 列「任务清单 + 数据小块」；下方通栏「学习热力」。
- 练习中心：顶部 5 个入口卡片（2×2 + 1 通栏），下方「最近记录」表。
- 答题页：题干区 8 列，右侧 4 列为答题卡与计时；< 1024 px 答题卡折叠为顶部横条。

## 8. 文案规范

- 动词开头，句子不超过 22 字：「开始 20 题模拟」「继续上次会话」。
- 数字带单位与口径：「正确率 78%（20 题中 16 题）」。
- 不用恐吓式催促（「你再不复习就完了」）；用事实陈述（「操作系统已 9 天未练」）。
- 概率与保底必须原样公示，不用模糊词（「大概率」）。
- 错误提示给出口：说明原因 + 一个可点的下一步。

## 9. 无障碍与国际化

- 对比度：正文 ≥ 4.5:1，大字号与图形 ≥ 3:1；科目色只作辅助，不单独承载信息。
- 所有图标按钮有 `aria-label`；答题选项为 `role="radio"`/`checkbox` 语义。
- 键盘：`1–4`/`A–D` 选项，`←/→` 切题，`M` 标记，`Esc` 关弹层，`Enter` 提交当前题/下一题。
- 动效遵循 `prefers-reduced-motion`；抽卡可跳过揭晓。
- v1.0 仅简体中文；文案抽为常量集中存放，预留 i18n 结构（见 13）。
