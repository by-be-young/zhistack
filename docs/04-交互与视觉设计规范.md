# 04 · 交互与视觉设计规范

## 1. 设计理念

**工业薄雾（Industrial Mist）**：把工科的秩序感（网格、刻度、等宽标注、硬边卡片）与备考的情绪需求（柔和、留白、可呼吸）叠在一起。界面像一张精密仪表盘，但底色不冷硬——用低饱和马卡龙色做状态与奖励，只在需要被看见的地方亮。

三条准则：
1. **结构先于装饰**：先让用户看清「在哪、剩多少、下一步做什么」，再谈氛围。
2. **一屏一个主动作**：每页只有一个视觉上最重的按钮，其余降级为描边或文字按钮。
3. **奖励克制**：抽卡与集章是收尾的仪式，不进入答题主流程，不遮挡题干。

## 3. 字体与排版

```
--font-sans: "Source Han Sans SC", "Noto Sans SC", "PingFang SC",
             "Microsoft YaHei", system-ui, sans-serif;
--font-mono: ui-monospace, "SFMono-Regular", "JetBrains Mono",
             "Cascadia Code", Consolas, monospace;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 40 / 1.15 | 650 | 首页主标题、大数字 |
| H1 | 28 / 1.25 | 600 | 页面标题 |
| H2 | 20 / 1.4 | 600 | 区块标题 |
| H3 | 16 / 1.5 | 600 | 卡片标题 |
| Body | 14.5 / 1.75 | 400 | 正文、题干 |
| Small | 13 / 1.6 | 400 | 说明、元信息 |
| Label | 11 / 1.2 | 500 | 等宽标签，`letter-spacing: 0.08em`，`text-transform: uppercase` |
| Num | 与 Display 同 | 600 | 数字使用 `font-variant-numeric: tabular-nums` |

规则：
- 中文正文不用 500 以下字重，避免细体发虚。
- 等宽只用于编号、页码、计时、题干中的公式与代码。
- 标题字距 `-0.01em`，正文 0；等宽标签 +0.08em。
- 段落最大行长 42 个汉字（约 `68ch`），超过则加宽容器或分栏。

### 3.1 正文阅读层（资料库 / 书库 / 材料栏）

长文阅读页不复用 UI 排版，另起一层 `--doc-*` 令牌（`src/styles/tokens.css`），排版规则集中在 `src/styles/notes.css`，渲染前处理在 `src/core/reading.js`。骨架参考 YoungBlog 文章详情页，色号按本站深色「工业薄雾」体系重调。

| 项 | 规格 |
| --- | --- |
| 标题字体 | `--font-display`：仓耳今楷 01 W04 子集（约 2 MB，`scripts/build-heading-font.py` 生成；缺失时回退 `--font-sans`） |
| 正文字体 | `--font-read`：Times New Roman + 思源宋体 / 宋体；代码、标签仍用 mono / sans |
| 正文字号 | 15 / 15.5 / 16.5 px 三档，行高 1.9，字距 0.01em，行长 ≤ 56 汉字（880 px 容器） |
| 标题层级 | 数据里的 h3–h5 在渲染前整体上提为 h1–h3，保证 h1 始终是正文顶层；目录层级同步换算 |
| 标题彩底 | h1 蓝 / h2 绿 / h3 橙 / h4 紫：左侧 3–5 px 色条 + 低透明度渐变底 + 8–12 px 圆角 + 轻投影；暗色透明度 11–13%，浅色 18–30% |
| 引用 | 1 px 描边 + 玫→薄荷→琥珀三段渐变竖条，卡片化内边距 |
| 表格 | 去竖线网格 + 表头彩底（仓耳今楷）+ 斑马纹 + 首列加粗；外层 `.doc-table` 负责横向滚动与圆角 |
| 代码 | 圆角 10、1 px 细线；深色主题下把源码写死的浅色行内颜色映射为同色系亮色（`DARK_SYNTAX`），保证高亮可读 |
| 图片 | 6 px 内边距 + 1 px 描边 + 12 px 圆角，居中；题注统一 0.78em、居中、弱色 |

## 4. 间距、圆角、描边、阴影

| 项 | 规格 |
| --- | --- |
| 间距基数 | 4 px；使用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 圆角 | 卡片 14 px；小组件 10 px；胶囊 999 px；内嵌块 8 px |
| 描边 | 默认 1 px `--line`；激活 1 px `--line-strong`；不使用粗描边 |
| 阴影 | 深色下不用投影，用「内高光」：`inset 0 1px 0 rgba(255,255,255,0.04)`；悬浮层用 `0 18px 48px rgba(0,0,0,0.45)` |
| 网格背景 | `repeating-linear-gradient` 32 px，透明度 0.035（深）/0.05（浅），仅页面底层 |
| 焦点环 | `0 0 0 2px var(--bg-0), 0 0 0 4px var(--mint)` |
| 最大内容宽 | 1280 px；左右安全边距 24（桌面）/16（移动） |

## 5. 动效

| 场景 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| 悬浮、按压 | 120 ms | `ease-out` | `translateY(-1px)`，不做放大 |
| 页面切换 | 200 ms | `cubic-bezier(.2,.8,.2,1)` | 淡入 + 上移 8 px |
| 弹层出现 | 240 ms | 同上 | 遮罩淡入，面板 0.96 → 1 |
| 抽卡揭晓 | 520 ms | `cubic-bezier(.16,1,.3,1)` | 卡面翻转 + 光晕扩散，只播一次 |
| SSR 光效 | 2400 ms 循环 | `linear` | 渐变扫光，`prefers-reduced-motion` 下静止 |
| 进度变化 | 320 ms | `ease-out` | 数值与环形同步 |
| Toast | 停留 2.4 s | 进出 180 ms | 顶部居中，最多堆叠 3 条 |

禁止：无限弹跳、无意义的位移动画、超过 600 ms 的阻塞式动效、抽卡过程中的强制等待（可点击跳过）。

## 6. 布局骨架

```
┌─────────────────────────────────────────────────────────────┐
│ Header：面包屑 · 当前科目过滤 · 积分 · 连击 · 主题 · 设置      │ 56px
├──────────┬──────────────────────────────────────────────────┤
│ NavRail  │  主内容区（max 1280，12 栅格，gutter 24）           │
│ 72px     │                                                  │
│ 图标 +    │  ┌───────────────┐ ┌───────────────┐             │
│ 竖排中文  │  │ 卡片 A (7col)  │ │ 卡片 B (5col) │             │
│          │  └───────────────┘ └───────────────┘             │
└──────────┴──────────────────────────────────────────────────┘
```

- NavRail 固定左侧，条目：总览 / 书库 / 知识点 / 练习 / 错题 / 卡册 / 任务 / 统计。当前项左侧 2 px 薄荷竖条 + 图标提亮。
- 移动端（< 900 px）NavRail 收起为底部 5 项快捷栏（总览 / 练习 / 错题 / 卡册 / 更多），其余进抽屉。
- 首页栅格：左 7 列「今日主线」（继续学习卡 + 薄弱点 3 条），右 5 列「任务清单 + 数据小块」；下方通栏「学习热力」。
- 练习中心：顶部 5 个入口卡片（2×2 + 1 通栏），下方「最近记录」表。
- 答题页：题干区 8 列，右侧 4 列为答题卡与计时；< 1024 px 答题卡折叠为顶部横条。

## 8. 文案规范

- 动词开头，句子不超过 22 字：「开始 20 题模拟」「继续上次会话」。
- 数字带单位与口径：「正确率 78%（20 题中 16 题）」。
- 不用恐吓式催促（「你再不复习就完了」）；用事实陈述（「操作系统已 9 天未练」）。
- 概率与保底必须原样公示，不用模糊词（「大概率」）。
- 错误提示给出口：说明原因 + 一个可点的下一步。

## 9. 无障碍与国际化

- 对比度：正文 ≥ 4.5:1，大字号与图形 ≥ 3:1；科目色只作辅助，不单独承载信息。
- 所有图标按钮有 `aria-label`；答题选项为 `role="radio"`/`checkbox` 语义。
- 键盘：`1–4`/`A–D` 选项，`←/→` 切题，`M` 标记，`Esc` 关弹层，`Enter` 提交当前题/下一题。
- 动效遵循 `prefers-reduced-motion`；抽卡可跳过揭晓。
- v1.0 仅简体中文；文案抽为常量集中存放，预留 i18n 结构（见 13）。

## 10. 页面视觉要点

| 页面 | 关键视觉 |
| --- | --- |
| 首页 | 顶部一行大字「今天，补哪一块」+ 当日数据微仪表；左侧大卡为「继续上次」，右侧为任务清单；底部 12 周热力条 |
| 书库 | 书目卡为「书脊」造型：左侧 6 px 科目色竖条，右侧标题与版次；详情页左侧章节树（树线细描边），右侧章节内容与跳页按钮 |
| 知识点 | 搜索框占满 8 列，下方结果行显示「高亮摘要 + 掌握度点阵」；详情页为大字号标题 + 等宽考点编号 + 要点列表（每项左侧 1 px 竖线） |
| 练习 | 五个入口卡带编号 `01–05`，卡片右下角显示「可用题量」；组卷面板为右侧抽屉 |
| 答题 | 极简：无导航栏（仅顶部细条显示科目与计时），题干居中偏左，选项间距 12，底部「上一题 / 标记 / 下一题」 |
| 结果 | 顶部大号分数与环形，下面「逐题复盘」列表按对错着色；右上角固定「再练一套」 |
| 卡册 | 网格 4 列，卡片有厚度感（下沿 2 px 深色边）；未获得为剪影 + 稀有度问号 |
| 抽卡 | 单抽居中大卡，十连为横向胶片条；背景为科目色径向渐变 + 细噪点 |
| 统计 | 左雷达右热力，下方折线；所有图表标注口径小字 |

## 11. 视觉验收清单

- [ ] 深浅两套主题下，所有文本对比度达标。
- [ ] 360 px 宽下无横向滚动，按钮可点区域 ≥ 44×44。
- [ ] 抽卡 SSR 与 N 卡在同一屏内可区分（颜色、边框、角标三重区分，非仅颜色）。
- [ ] 长题干（300 字 + 代码块）不溢出卡片，代码块可横向滚动。
- [ ] 10 连抽结果页在移动端可横滑，且不遮挡关闭按钮。
