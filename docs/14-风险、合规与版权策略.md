## 2. 版权策略

### 2.1 内容分级

| 内容 | 版权状态 | 是否入库 | 说明 |
| --- | --- | --- | --- |
| 书目信息（书名/作者/版次/出版社/页数） | 事实性信息 | 是 | 不受著作权保护的事实 |
| 教材目录标题 | 事实性目录 | 是 | 仅标题，不含正文与图表 |
| 章节起始页码 | 事实性数据 | 是 | 需标注版次 |
| 知识点摘要与要点 | 原创 | 是 | 独立撰写，不转述原文 |
| 练习题与解析 | 原创 / 改编 | 是 | 改编题标注年份与「改编」 |
| 真题原文（题干/选项/答案） | 受版权保护 | 否 | 不复制、不上传、不内置 |
| 教材 PDF / 扫描件 | 受版权保护 | 否 | 用户本地挂载，不随仓库分发 |
| 教材图表 | 受版权保护 | 否 | 不使用；自制示意图用 CSS/SVG |

### 2.2 「改编」的边界

合规的改编：使用同一考点、重设情境与数值、重写选项、独立撰写解析。

不合规：替换个别数字后照搬题干句式、照抄选项、复述原解析。

判定标准：把改编题与疑似原题并排比较，若「不看答案也能认出是同一道题」，则视为过度接近，需重写。

### 2.3 用户导入内容的处理

- 用户挂载的 PDF 只存本地，不进入存档导出，不上传。
- 若未来支持导入题目 JSON，需在导入界面提示「请确保你有权使用该内容」。

### 2.4 声明文案（站点与 README）

> 本站知识点、题目与解析为个人复习整理的原创内容，书目信息为公开出版信息。本站不提供、不分发任何教材正文或真题原文。教材 PDF 由使用者自行准备并在本地浏览器挂载，文件不会上传。

## 3. 隐私与数据安全

| 项 | 策略 |
| --- | --- |
| 账号 | 不设账号，不收集身份信息 |
| 埋点 | 无。不使用任何分析 SDK |
| 网络 | 除静态资源外无请求；不加载外部字体与 CDN |
| 存储 | 仅浏览器本地；导出文件由用户自行保管 |
| PDF | 仅本地 IndexedDB；可随时删除；不写入导出存档 |
| 第三方 | 无第三方脚本、无 cookie、无广告 |
| 未成年人 | 内容为考研学习资料，不含社交与付费，无风险场景 |

## 4. 内容准确性治理

1. **来源标注**：知识点可选 `sourceNote`（如「依据 XX 教材第 3 章概念整理」），不引用原文。
2. **复核机制**：撰写与复核分离，间隔 ≥ 24 小时；高风险点（计算类、协议细节）二次核对。
3. **纠错入口**：知识点与题目详情提供「内容有误？」链接，指向仓库 Issue 模板（不含个人信息）。
4. **版本记录**：`dataVersion` 与 Git 提交对应，可按版本回溯某条内容的变更。
5. **免责**：README 与设置页说明「内容供复习参考，以教材与官方大纲为准」。

## 5. 合规检查清单（发布前）

- [ ] 仓库中无 PDF、无扫描图片、无教材正文片段。
- [ ] 所有内置题 `source` 字段正确，改编题有 `year` 与 UI 标注。
- [ ] 知识点文本与教材原文无整段雷同（抽查 10 条）。
- [ ] 站点无第三方请求（DevTools Network 检查）。
- [ ] 导出文件不含设备标识与个人信息。
- [ ] 概率与保底文案与实际配置一致。
- [ ] README 版权声明存在且链接可达。

## 6. 事件响应

| 事件 | 响应 |
| --- | --- |
| 收到版权投诉 | 立即下架相关内容（改 `retired` 或删除），保留沟通记录，24 小时内处理 |
| 发现内容错误 | 24 小时内修正并发布，`dataVersion` +1，文档记录 |
| 用户反馈数据丢失 | 引导从备份/导出恢复；必要时提供「从明细重建」 |
| 站点被举报 | 可临时 Unpublish，保留仓库；核查内容后决定恢复或调整 |
