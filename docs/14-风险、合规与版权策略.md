# 14 · 风险、合规与版权策略

## 1. 风险清单

| 编号 | 风险 | 等级 | 影响 | 缓解 |
| --- | --- | --- | --- | --- |
| R-01 | 教材正文入库体量 | 低 | 仓库变大 | 正文按节拆分、按需加载；不影响首屏 |
| R-02 | 真题原文入库 | 低 | — | 直接收录，按卷归档，不进入随机组卷 |
| R-03 | 知识点内容错误误导备考 | 高 | 学习效果受损 | 交叉复核、提供反馈入口 |
| R-04 | 本地存档丢失 | 中 | 进度清零 | 三次备份、导出、重建统计 |
| R-05 | 概率机制引发争议 | 中 | 信任下降 | 概率公示、保底可见、历史可查、无付费 |
| R-06 | 过度游戏化挤占学习 | 中 | 本末倒置 | 积分日上限、抽卡不驱动刷题、奖励延迟结算 |
| R-07 | 静态站点无访问控制 | 低 | 内容公开 | 内容本身为公开学习资料；不含个人数据 |
| R-08 | 依赖浏览器存储被清理 | 低 | 同上 | 提示用户定期导出 |
| R-09 | 数据文件体积膨胀 | 低 | 首屏变慢 | 构建校验、按科目拆包预案 |
| R-10 | 时间口径混乱导致统计偏差 | 中 | 数据不可信 | 统一 `dayKey`（04:00 分界），集中实现 |

## 2. 内容范围与来源

本站是私人复习工作台，内容统一按「个人学习使用」处理，**不对外分发、不标注来源、不做来源核验**。

| 内容 | 是否入库 | 说明 |
| --- | --- | --- |
| 书目信息（书名/作者/版次/出版社/页数） | 是 | 原样登记，可加注版次用于页码校准 |
| 教材目录、正文、图表、例题 | 是 | 可整本入库；扫描件可 OCR 成站内正文，也可本地挂载 PDF |
| 知识点摘要与要点 | 是 | 自写或整理均可 |
| 练习题、真题、解析 | 是 | 直接使用，无需标注年份、来源或「改编」 |
| 讲义、笔记、资料镜像 | 是 | 直接入库 |

约定：

- 不再要求任何「来源链接 / 改编标记 / 版权声明」字段；内容字段只服务检索与阅读。
- 站点只做一件事：把手上材料变成可搜索、可跳转、可作答的电子资料。
- 若站点将来公开对外分发，再按届时需要单独处理来源与授权，不写进当前规范。

## 3. 隐私与数据安全

| 项 | 策略 |
| --- | --- |
| 账号 | 不设账号，不收集身份信息 |
| 埋点 | 无。不使用任何分析 SDK |
| 网络 | 除静态资源外无请求；不加载外部字体与 CDN |
| 存储 | 仅浏览器本地；导出文件由用户自行保管 |
| PDF | 仅本地 IndexedDB；可随时删除；不写入导出存档 |
| 第三方 | 无第三方脚本、无 cookie、无广告 |
| 未成年人 | 内容为考研学习资料，不含社交与付费，无风险场景 |

## 4. 内容准确性治理

1. **来源登记可选**：知识点可留 `sourceNote` 作为私人备忘，可空；不要求对外标注。
2. **复核机制**：撰写与复核分离，间隔 ≥ 24 小时；高风险点（计算类、协议细节）二次核对。
3. **纠错入口**：知识点与题目详情提供「内容有误？」链接，指向仓库 Issue 模板（不含个人信息）。
4. **版本记录**：`dataVersion` 与 Git 提交对应，可按版本回溯某条内容的变更。
5. **免责**：README 与设置页说明「内容供复习参考，以教材与官方大纲为准」。

## 5. 合规检查清单（发布前）

- [ ] 正文与题目体积可控，按节懒加载生效。
- [ ] 站点无第三方请求（DevTools Network 检查）。
- [ ] 导出文件不含设备标识与个人信息。
- [ ] 概率与保底文案与实际配置一致。

## 6. 事件响应

| 事件 | 响应 |
| --- | --- |
| 发现内容错误 | 24 小时内修正并发布，`dataVersion` +1，文档记录 |
| 用户反馈数据丢失 | 引导从备份/导出恢复；必要时提供「从明细重建」 |
| 站点被举报 | 可临时 Unpublish，保留仓库；核查内容后决定恢复或调整 |

## 7. 免责声明

本站为个人学习工具，内容仅供参考，不构成任何形式的备考承诺或结果保证。使用者应自行核对内容准确性，并以教育部考试大纲与正式出版教材为准。
