# 18 · 真题原卷与主观题自评

> 版本：v1.2
> 状态：已实现（2024 · 408、2024 · 政治）
> 关联：03 领域模型、06 命题规范、08 诊断算法、11 测试验收、14 合规策略

## 1. 目标与边界

### 1.1 要解决的问题

原创题适合日常组卷，但冲刺阶段需要按真实卷面结构、分值和时间做整套训练。真题模块承担三件事：

1. **原卷完整呈现**：题干、选项、分值、题号与真实试卷一致，不改写、不拆题。
2. **整卷计时**：按科目真实考试时长倒计时，交卷后统一判分。
3. **主观题可自评**：解答题、综合应用题、材料分析题无法自动判分，由用户在参考答案与评分要点辅助下选择得分比例。

### 1.2 不做的事

- 不做题库式拆解：原卷不进入随机组卷池，避免真题被抽散。
- 不复制教材或教辅解析：客观题解析为知栈撰写的简短说明，主观题参考答案按评分点整理。
- 不承诺押题：真题只用于结构训练与自评，不代表当年命题方向。
- 不内置图形：带图题目保留原卷来源与页码提示，图形以原卷 PDF 为准。

## 2. 数据结构

### 2.1 试卷对象

```js
{
  id: 'paper-2024-408',
  year: 2024,
  title: '2024 年全国硕士研究生招生考试 408 计算机学科专业基础',
  short: '2024 408 原卷',
  group: '408',                 // 408 / math / en / pol
  subjects: ['ds', 'co', 'os', 'cn'],
  durationMin: 180,
  totalScore: 150,
  questionCount: 47,
  qids: ['q-408-2024-01', ...],
  sourceName: '公开网络版（厦门工学院试卷 PDF）',
  sourceUrl: 'https://...',
  answerUrl: 'https://...',
  note: '版权与图形说明'
}
```

试卷只保存题目 id 顺序与卷面元信息，题干放在独立题目对象中，便于按知识点反向索引。

### 2.2 主观题字段

```js
{
  id: 'q-408-2024-41',
  type: 'subjective',
  score: 13,
  stem: '……',
  referenceAnswer: '……',        // 参考答案，支持 Markdown
  rubric: [                      // 评分要点，points 之和必须等于 score
    { text: '设计思想', points: 2 },
    { text: '代码与边界', points: 11 }
  ],
  explain: '自评提示',
  paperId: 'paper-2024-408',
  paperOnly: true,
  source: 'real',
  year: 2024,
  number: 41,
  sourceUrl: 'https://...'
}
```

客观题沿用原有结构，增加 `score`、`number`、`paperId`、`paperOnly`、`source: 'real'`。`paperOnly` 让原卷题目不进入随机组卷、真题改编与错题重练池。

### 2.3 聚合方式

```
src/data/papers/2024-408.js   → 47 道题 + 1 个试卷对象
src/data/papers/index.js      → papers / paperById / papersByYear / papersBySubject
src/data/questions/index.js   → questions（原创池）
                                paperQuestions（原卷题）
                                allQuestions（全部，供 questionById 使用）
```

`questionById` 覆盖全部题目，保证结果页、错题本、知识点详情都能解析原卷题；`questions` 保持原创池不变，避免题库统计被真题稀释。

## 3. 作答流程

```
真题列表 → 创建 paper 会话 → 逐题作答（客观选项 / 主观文本）
        → 交卷确认 → 主观题自评弹窗 → 完成自评并交卷
        → 结果页（卷面分、折合百分比、逐题解析）
```

### 3.1 客观题

- 单选、判断：点击即选中，可改选。
- 多选：全部选对得满分；漏选（所选均正确但不全）得半分；错选不得分。
- 未作答计 0 分，并计入错题。

### 3.2 主观题

- 作答区为纯文本，最多不限制字数，实时显示字数。
- 答案随草稿写入 `session.answers[qid]`，只保存在本机 localStorage。
- 交卷时若卷面含主观题，弹出「主观题自评」：
  - 每题展示题号、满分、参考答案、评分要点；
  - 提供 0 / 20 / 40 / 60 / 80 / 100 六档比例；
  - 实时显示本题折算得分；
  - 全部确认后交卷。
- 超时自动交卷时跳过自评，主观题按 0 分计，避免阻塞。

### 3.3 计分规则

```
主观题得分 = 题目满分 × 自评比例
卷面得分   = Σ 各题得分（客观题按 0 / 0.5 / 1 权重）
折合百分比 = 卷面得分 / 卷面满分 × 100，四舍五入
答对判定   = 客观题全对；主观题自评比例 ≥ 60%
```

结果页同时展示「卷面得分 / 满分」和「折合百分比」，避免 150 分制与百分制混淆。

## 4. 与现有系统的衔接

| 模块 | 处理 |
| --- | --- |
| 组卷 | `buildPaper` 过滤 `paperOnly`，原卷题不会被随机抽中 |
| 统计 | 原卷会话正常计入会话数、题量、正确率；主观题按 60% 阈值计入答对 |
| 错题本 | 仅客观题入本；主观题不生成错题，避免无法重练 |
| 掌握度 | 主观题按比例计入，60% 以上视为该考点一次正确 |
| 积分 | 按原会话规则结算，不因卷面分高而额外放大 |
| 成就 | 「第一套卷」等按会话计数，原卷同样触发 |
| 存档 | 会话新增 `paperId`、`paperTitle`、`rawPoints`、`totalPoints`，旧字段不变 |

### 4.1 存档兼容

`settings`、`sessions` 结构只增字段，`schemaVersion` 保持 2。旧存档导入后：

- 历史会话没有 `paperId`，按普通练习展示；
- 新原卷会话可正常回放；
- 主观题 `selfGrades` 缺省视为 0，不会报错。

## 5. 页面与交互

### 5.1 真题列表 `/papers`

- 顶部按 408 / 数学 / 英语 / 政治筛选，按年份倒序分组。
- 卡片展示题量、时长、满分、科目色、作答次数与最高分。
- 提供「原卷来源」外链，便于核对图形题。
- 底部固定说明版权、图形与自评口径。

### 5.2 作答页

- 沿用练习页布局：左侧题卡、右侧答题卡、顶部计时。
- 主观题题干下方直接给出文本域，不显示选项。
- 答题卡中已作答状态按“有文本”判断。
- 交卷确认弹窗提示未答题数量；含主观题时进入自评弹窗。

### 5.3 结果页

- 卷面分主视觉：大号卷面得分 + 满分 + 折合百分比。
- 逐题解析：客观题显示正误与正确选项；主观题显示自评比例、我的作答、参考答案、评分要点。
- 主观题不进入「重练错题」按钮统计。

## 6. 内容来源与合规

- 题干来自公开网络流传的试卷 PDF，入库时逐题校对，不改写。
- 参考答案与评分要点由知栈按题目结构整理，不直接复制教辅解析。
- 图形题保留原卷页码提示与来源链接，不将扫描图二次分发。
- 页面标注「版权归权利人，仅个人复习，异议即移除」。
- 公共课原卷中，政治已完成 2024 全套；数学、英语涉及大量公式与长篇幅原文，入库前需单独评估排版、授权与篇幅。

## 7. 边界情况

| 情况 | 处理 |
| --- | --- |
| 图形题缺图 | 显示 `figureNote` 与原卷来源，题干其余部分完整 |
| 主观题未作答但自评 80% | 允许，但结果页标注“未作答”；自评仅影响得分 |
| 主观题自评后想改 | 当前在交卷前可反复调整；交卷后不回溯改分 |
| 中途退出 | 草稿保留 24 小时，含主观文本与已选自评比例 |
| 超时 | 自动交卷，主观题记 0 |
| 题号与卷面不一致 | 由 `number` 字段显式保存，不依赖数组下标 |
| 试卷题目缺失 | 构建校验报错，阻断部署 |
| 评分要点合计不等于满分 | 构建校验报错 |

## 8. 扩展方式

新增一套原卷：

1. 新建 `src/data/papers/<year>-<group>.js`，导出 `questions` 与 `paper`；
2. 在 `papers/index.js` 注册；
3. 在 `questions/index.js` 聚合题目；
4. 运行 `node scripts/validate-data.mjs`，确认题号、分值、评分要点与引用完整；
5. 构建后在 `/papers` 验证筛选、计时、自评与结果页。

新增公共课原卷时，`group` 取 `math` / `en` / `pol`，`subjects` 可含单科或多科；英语阅读原文需先确认授权，未授权时只收录主观题部分并标注“节选”。
