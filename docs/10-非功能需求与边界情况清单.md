# 10 · 非功能需求与边界情况清单

## 1. 非功能需求

### 1.1 性能

| 编号 | 指标 | 目标 | 测量条件 |
| --- | --- | --- | --- |
| NFR-P-01 | 首屏可交互（TTI） | ≤ 1.5 s | 生产构建、本地静态服务、中端笔电（4 核 / 8 GB） |
| NFR-P-02 | 路由切换 | ≤ 200 ms | 非首次进入的懒加载页 |
| NFR-P-03 | 知识点检索 | ≤ 30 ms | 140 条知识点、3 字关键词 |
| NFR-P-04 | 组卷 | ≤ 20 ms | 题池 160、题量 30 |
| NFR-P-05 | 交卷全流程 | ≤ 50 ms | 30 题评分 + 聚合 + 写档 |
| NFR-P-06 | 存档写入 | ≤ 10 ms | 200 KB |
| NFR-P-07 | 抽卡一次（含动画启动） | ≤ 16 ms 计算 + 520 ms 动画 | 十连计算 ≤ 8 ms |
| NFR-P-08 | 统计页渲染 | ≤ 120 ms | 500 会话条 + 12 周热力 |
| NFR-P-09 | 包体（gzip） | ≤ 180 KB | 不含 PDF 与数据图片 |

### 1.2 可靠性

| 编号 | 要求 |
| --- | --- |
| NFR-R-01 | 存档损坏可恢复：三次备份回退 + 损坏原文可下载 |
| NFR-R-02 | 写入失败不丢内存态，重试最多 3 次后进入只读并提示 |
| NFR-R-03 | 未交卷会话可恢复（24 h 内），恢复准确率 100% |
| NFR-R-04 | 幂等：同一会话重复提交不重复发积分、不重复入错题 |
| NFR-R-05 | 单页异常不扩散，其他路由可正常使用 |
| NFR-R-06 | 内容下架不产生空白页，历史记录可复盘 |

### 1.3 兼容性

| 编号 | 要求 |
| --- | --- |
| NFR-C-01 | Chromium ≥ 110、Safari ≥ 16、Firefox ≥ 110 可用 |
| NFR-C-02 | 360×640 至 2560×1440 无布局错乱 |
| NFR-C-03 | 无 `File System Access API` 时 PDF 走 Blob 降级并明确提示 |
| NFR-C-04 | `prefers-color-scheme` 与 `prefers-reduced-motion` 正确响应 |
| NFR-C-05 | 输入法组合输入（中文）时不误触发快捷键 |

### 1.4 安全与隐私

| 编号 | 要求 |
| --- | --- |
| NFR-S-01 | 无远程请求（除首屏静态资源）；无第三方脚本、字体、埋点 |
| NFR-S-02 | 所有用户/内容文本按纯文本渲染，禁止 `v-html` 渲染未净化内容 |
| NFR-S-03 | 导入 JSON 只按白名单字段读取，不执行任意代码 |
| NFR-S-04 | PDF 不出本机；导出文件不含设备与身份信息 |
| NFR-S-05 | 外链使用 `noopener noreferrer` |

### 1.5 可维护性

| 编号 | 要求 |
| --- | --- |
| NFR-M-01 | 领域层纯函数，单文件 ≤ 400 行；组件 ≤ 300 行 |
| NFR-M-02 | 数据变更必须通过 `validate-data` |
| NFR-M-03 | 视觉令牌集中，禁止组件内写裸色值（除纹样渐变） |
| NFR-M-04 | 所有魔法数字（积分、阈值、概率）集中在 `core/config.js` |

### 1.6 可用性

| 编号 | 要求 |
| --- | --- |
| NFR-U-01 | 新用户 30 秒内可完成第一道题（无需注册与配置） |
| NFR-U-02 | 主流程（检索 → 书页 → 练习 → 复盘）每步 ≤ 2 次点击 |
| NFR-U-03 | 键盘可完成整套练习 |
| NFR-U-04 | 空态均有解释与出口，不出现「暂无数据」孤句 |

## 2. 边界情况清单

分类：`EDGE-UI` 界面、`EDGE-DATA` 数据、`EDGE-BIZ` 业务、`EDGE-EXT` 外部依赖、`EDGE-TIME` 时间。

### 2.1 界面

| 编号 | 场景 | 期望行为 |
| --- | --- | --- |
| EDGE-UI-01 | 题干 400 字 + 代码块 + 公式 | 卡片内换行，代码块横滚，不撑破布局 |
| EDGE-UI-02 | 选项文本长度差异极大 | 选项块等高自适应，左侧对齐，不截断 |
| EDGE-UI-03 | 360 px 宽 + 十连结果 | 横向滚动，关闭按钮固定可见 |
| EDGE-UI-04 | 系统字号放大 150% | 不重叠，列表可滚动 |
| EDGE-UI-05 | 深色模式下截图分享 | 关键信息不依赖纯色块辨识（有文字标签） |
| EDGE-UI-06 | 超长知识点标题（> 24 字） | 两行截断 + 详情页完整展示 |
| EDGE-UI-07 | 无封面/无图标数据 | 使用科目色几何占位，不显示破图 |
| EDGE-UI-08 | 抽卡动画被快速点击 | 可跳过，结果立即展示，不重复扣分 |
| EDGE-UI-09 | 弹层叠加（设置 → 确认清空 → Toast） | 层级正确，Esc 逐层关闭 |
| EDGE-UI-10 | 浏览器缩放 50% / 200% | 栅格自适应，不出现横向滚动 |

### 2.2 数据

| 编号 | 场景 | 期望行为 |
| --- | --- | --- |
| EDGE-DATA-01 | localStorage 被手动清空 | 重新初始化空档，引导页出现，无报错 |
| EDGE-DATA-02 | 存档 JSON 被截断 | 解析失败 → 备份回退；失败则空档 + 可下载损坏原文 |
| EDGE-DATA-03 | 存档字段类型错误（points 为字符串） | `repair` 转数字或归零，记录日志 |
| EDGE-DATA-04 | 导入高版本存档 | 拒绝，提示版本不符 |
| EDGE-DATA-05 | 导入存档 checksum 不符 | 二次确认后可强制导入 |
| EDGE-DATA-06 | 配额写满 | 捕获异常 → 提示清理 → 只读模式 |
| EDGE-DATA-07 | 题量 0 的科目 | 练习入口禁用并说明「本科目题库待补」 |
| EDGE-DATA-08 | 知识点无关联题 | 详情页显示「暂无配套题」+ 相邻知识点推荐 |
| EDGE-DATA-09 | 题目主考点已删除 | 题标记下架，不进入组卷，历史复盘显示原题干 |
| EDGE-DATA-10 | 多标签页同时写 | 后写检测冲突，提示并合并 |
| EDGE-DATA-11 | IndexedDB 被禁用（隐私模式） | PDF 功能降级，其余功能正常 |
| EDGE-DATA-12 | 存档含未知字段 | 保留不删除，迁移时忽略 |

### 2.5 时间

| 编号 | 场景 | 期望行为 |
| --- | --- | --- |
| EDGE-TIME-01 | 03:58 答题，04:02 交卷 | 答题计前一日，交卷奖励计当日；任务按当日重置 |

| EDGE-TIME-04 | 系统时间回拨 1 年 | 近因计算按 0 天，记录异常标记 |
| EDGE-TIME-05 | 会话跨越 04:00 | 会话记录归属开始日，日度统计按答题时刻拆分 |
| EDGE-TIME-06 | 闰日 / 月末 | `dayKey` 基于本地日期计算，不手写月份天数 |
| EDGE-TIME-07 | 长时间休眠后恢复 | 检查 `day-rollover`，刷新任务与打卡状态 |

## 3. 降级矩阵

| 能力缺失 | 降级方案 | 用户提示 |
| --- | --- | --- |
| localStorage 不可用 | 内存模式（刷新即丢） | 顶部常驻条「当前无法保存进度」 |
| IndexedDB 不可用 | 不提供 PDF 挂载 | 书库页说明「当前浏览器不支持本地挂载」 |
| 文件句柄 API 缺失 | Blob URL（会话内有效） | 「刷新后需重新挂载」 |
| 动画偏好关闭 | 静态展示结果 | 无提示 |
| 配额不足 | 只读 + 清理入口 | Toast + 设置页警告 |
| 数据包加载失败 | 显示错误页 + 重试按钮 | 「内容加载失败，请检查网络后重试」 |
