# 知栈 ZHI·STACK — 考研知识库平台

> 把公共课与 408 的「书、点、题、错、奖」收进同一个工作台。
> 线上站点：<https://by-be-young.github.io/zhistack/>

知栈是一个纯前端的考研备考工作台，覆盖 **数学（一）、英语（一）、政治** 三门公共课与 **408** 四门专业课。它不替代教材，而是把教材、知识点、题库、错题、复习任务和薄弱点诊断串成一条可执行的学习链路：**查到知识 → 打开对应书页 → 做完配套题 → 错题回流 → 系统告诉你下一题该刷哪里 → 积分与抽卡给正反馈**。

---

## 1. 功能矩阵

| 模块 | 能力 | 关键设计 |
| --- | --- | --- |
| 书库 | 七科书目（408 四本 + 数学三本 + 英语讲义 + 政治大纲解析）、章节树、页码映射、本地 PDF 挂载、按章节一键跳页 | PDF 正文不入库，只存公开书目元数据与页码索引，规避版权风险 |
| 知识点 | 全文检索（标题 / 标签 / 正文 / 考点编号）、按科目与章节浏览、掌握度、关联题与关联书页 | 检索采用「分词 + 字段加权 + 高亮」的本地实现，无需后端 |
| 真题 | 按年份整套原卷作答、真实分值、180 分钟计时、主观题对照参考答案按 0–100% 自评 | 题干不改写；原卷独立成包，不进入随机组卷；图形题保留原卷来源 |
| 作答体验 | 长材料独立成栏（分块、字号、独立滚动、滚动位置记忆）、手写草稿层随内容滚动且切题即清、KaTeX 公式渲染 | 材料栏桌面 sticky 三栏、移动端纵向堆叠；英语阅读宽栏、完形自动定位空号；草稿不落盘不导出；公式失败回退代码文本 |
| 练习 | 模拟卷（按科目与题量随机组卷、限时）、薄弱专项、错题重练；原卷从「真题」入口整套作答 | 原创题用于日常组卷；原卷题只服务整卷训练 |
| 错题 | 自动入错题本、按科目 / 错误次数 / 最近错误排序、错题重练、连续答对自动出本 | 错题状态机：`new → reviewing → mastered`，答对两次升档 |
| 激励 | 积分、等级、每日打卡、连击、抽卡、知识卡图鉴、集章册、限定卡池 | 抽卡用积分消耗 + 保底计数，避免纯概率挫败；卡面为原创知识卡 |
| 任务 | 每日任务、每周任务、成就、进度自动结算 | 任务状态由事件总线推导，刷新页面不丢进度 |
| 诊断 | 按知识点聚合正确率、错误次数、掌握度，输出薄弱点排行与推荐练习 | 加权评分：正确率 + 近因衰减 + 题量置信度，冷启动回退到章节权重 |
| 统计 | 学习日历、科目雷达、答题趋势、错题分布 | 全部本地计算，可导出 JSON |
| 资料库 | 425 篇站内镜像讲义与真题（数据结构 / 组成原理 / 操作系统 / 计算机网络 / 408 真题 / 数学真题 / 学习心法 / 英语 / 政治 / 代码实现），支持全文搜索、栏目筛选、高频考点标记、目录定位与图示渲染 | 页面数据 gzip 存放、按需解压；SVG 图示由 drawio 内联导出后清洗为独立文件，保留 `foreignObject` 文字标签 |
| 数据 | 导入 / 导出学习存档、清空数据、多设备手工迁移 | 单键版本化存档，带 schema 版本与迁移钩子 |

当前内容规模：**153 个知识点 · 164 道原创题 · 8 套真题原卷（2024 408 / 政治 / 数学一 / 英语一，2023 408 / 英语一 / 政治 / 数学一，共 318 题）· 9 本书目 · 84 张知识卡 · 425 篇站内资料镜像**。

## 2. 技术栈

- Vue 3（`<script setup>`）+ Vite 6 + Vue Router 4 + 自建 reactive store（无 Pinia）
- 纯静态部署：GitHub Pages + GitHub Actions
- 无后端依赖：题库与知识点为构建期打包的静态数据；学习进度存 `localStorage`；本地 PDF 句柄与文件存 `IndexedDB`
- 样式：原生 CSS 变量 + 设计令牌（无 UI 框架），自定义「工业薄雾 + 马卡龙点缀」视觉体系
- 图表：手写 SVG（雷达、环形、柱状），不引入重型图表库
- 公式：KaTeX 0.16 本地渲染，按需打进 `RichText` chunk，不依赖 CDN
- 手写：Pointer Events + Canvas，DPR 缩放，笔迹只存在内存

## 3. 本地开发

```bash
npm install
npm run dev      # http://localhost:5173/zhistack/
npm run build    # 产物在 dist/
npm run preview
```

> 部署在子路径 `/zhistack/` 下，Vite `base` 已固定，路由使用 hash 模式，避免 Pages 刷新 404。

## 4. 部署

推送到 `main` 即触发 `.github/workflows/deploy.yml`：安装依赖 → 构建 → 上传 `dist` → 发布 Pages。仓库需在 Settings → Pages 中将 Source 设为 **GitHub Actions**。
