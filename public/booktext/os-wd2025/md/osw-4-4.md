# 4.4 本章疑难点

### 1. 文件的物理分配方式的比较

文件的三种物理分配方式的比较如表4.3所示。

**表4.3文件三种分配方式的比较**

| 列1 | 访问第n条记录 | 优点 | 缺点 |
| --- | --- | --- | --- |
| | | 顺序存取时速度快，文件定长时可根据文 | 文件存储要求连续的存储空间，会产生碎 |
| 连续分配 | 需访问磁盘1次 | | |
| | | 件起始地址及记录长度进行随机访问 | 片，不利于文件的动态扩充 |
| | | 可解决外存的碎片问题，提高外存空间的 | 只能按照文件的指针链顺序访问，查找效 |
| 链接分配 | 需访问磁盘n次 | | |
| | | 利用率，动态增长较方便 | 率低，指针信息存放消耗外存空间 |
| 索引分配 | m级需访问磁盘m+1次 | 可以随机访问，文件易于增删 | |

①检索目录，要求打开的文件应该是已经创建的文件，它应登记在文件目录中，否则会出错。在检索到指定文件后，就将其磁盘iNode复制到活动iNode表中。

②将参数mode所给出的打开方式与活动iNode中在创建文件时所记录的文件访问权限相比较，如果合法，则此次打开操作成功。

③当打开合法时，为文件分配用户打开文件表表项和系统打开文件表表项，并为后者设置初值，通过指针建立表项与活动iNode之间的联系，再将文件描述符fd返回给调用者。
